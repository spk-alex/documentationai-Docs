# Matter Cluster 1287 — Media Input Cluster

<Callout type="info">
Matter Cluster <code>1287</code>, also written as <code>0x0507</code>, is the <strong>Media Input Cluster</strong>.
This cluster provides an interface for controlling the Input Selector on a media device such as a Video Player. This cluster would be implemented on TV and other media streaming devices, as well as devices that provide input to or output from such devices. This cluster provides the list of available inputs and provides commands for selecting and renaming them.
</Callout>

## Cluster 1287 Features

The `FeatureMap` attribute (`1/1287/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `NU` | NameUpdates | `O` | Supports updates to the input names |

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1287,
    "command_name": "SelectInput",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1287, always use `"cluster_id": 1287`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
