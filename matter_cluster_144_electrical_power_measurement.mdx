# Matter Cluster 144 — Electrical Power Measurement Cluster

<Callout type="info">
Matter Cluster <code>144</code>, also written as <code>0x0090</code>, is the <strong>Electrical Power Measurement Cluster</strong>.
This cluster provides a mechanism for querying data about electrical power as measured by the server.
</Callout>

## Cluster Identity

| Field | Value |
|---|---|
| Cluster ID decimal | `144` |
| Cluster ID hex | `0x0090` |
| Cluster name | `Electrical Power Measurement` |
| Cluster revision (Matter 1.6.1) | `3` |
| Role | application |
| Scope | Endpoint |
| PICS code | `EPM` |
| Typical endpoint | `1` |

### Revision history

| Revision | Change |
|---:|---|
| 1 | Initial revision |

## Cluster 144 Features

The `FeatureMap` attribute (`1/144/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `DIRC` | DirectCurrent | `O` | Supports measurement of direct current |
| 1 | `ALTC` | AlternatingCurrent | `O` | Supports measurement of alternating current |
| 2 | `POLY` | PolyphasePower | `[ALTC]` | Supports polyphase measurements |
| 3 | `HARM` | Harmonics | `[ALTC]` | Supports measurement of AC harmonics |
| 4 | `PWRQ` | PowerQuality | `[ALTC]` | Supports measurement of AC harmonic phases |

Example: `FeatureMap` = `0` means no optional feature is enabled; `31` means every feature listed above is enabled.
