# Matter Cluster 65 — User Label Cluster

<Callout type="info">
Matter Cluster <code>65</code>, also written as <code>0x0041</code>, is the <strong>User Label Cluster</strong>.
This cluster is derived from the Label cluster and provides a feature to tag an endpoint with zero or more writable labels.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Label cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `LabelList`

Path example:

```text
1/65/0
```

The server must support the storage of up to 4 list entries in this attribute. The server may support the storage of more than 4 entries in this attribute. When reading from this attribute, the server must respond with the actual contents of the attribute which may contain any number of entries (possibly more than 4), When writing to this attribute, a client may include any number of entries to be written, or none at all. If an attempt is made to write to this attribute with a list length that is not supported by the server, the server must respond with RESOURCE_EXHAUSTED.

| Property | Value |
|---|---|
| Type | list of LabelStruct |
| Conformance | `M` |
| Access | R/W (read: view, write: manage) |
| Qualities | persisted |
| Constraint | desc |
| Default | `empty` |

Each entry is a `LabelStruct` (see Data Types).

Example:

```json
{
  "1/65/0": []
}
```

# Cluster 65 Commands

Cluster 65 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 65 Events

Cluster 65 defines **no events**.
