# Matter Cluster 37 — Actions Cluster

<Callout type="info">
Matter Cluster <code>37</code>, also written as <code>0x0025</code>, is the <strong>Actions Cluster</strong>.
This cluster provides a standardized way for a Node (typically a Bridge, but could be any Node) to expose logical grouping and actions. Specifically this cluster provides: - Information about logical grouping of endpoints on the Node (example: lights in a room) - Information about named actions that can be performed on such a group of endpoints (example: recall a scene for a group of lights by its name) - Commands to trigger such actions - Events to receive feedback on the state of such actions.
</Callout>

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 37,
    "command_name": "InstantAction",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 37, always use `"cluster_id": 37`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

## Event `0` — `StateChanged`

This event is generated when there is a change in the State of an ActionID during the execution of an action and the most recent command using that ActionID used an InvokeID data field. It provides feedback to the client about the progress of the action. Example: When InstantActionWithTransition is invoked (with an InvokeID data field), two StateChanged events will be generated: - one when the transition starts (NewState=Active) - one when the transition completed (NewState=Inactive)

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `ActionID` | uint16 | `M` | — |
| 1 | `InvokeID` | uint32 | `M` | — |
| 2 | `NewState` | ActionStateEnum | `M` | This field is set to state that the action has changed to. |

## Event `1` — `ActionFailed`

This event is generated when there is some error which prevents the action from its normal planned execution and the most recent command using that ActionID used an InvokeID data field. It provides feedback to the client about the non-successful progress of the action.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `ActionID` | uint16 | `M` | — |
| 1 | `InvokeID` | uint32 | `M` | — |
| 2 | `NewState` | ActionStateEnum | `M` | This field is set to state that the action is in at the time of generating the event. |
| 3 | `Error` | ActionErrorEnum | `M` | This field is set to indicate the reason for non-successful progress of the action. |
