# Matter Cluster 1283 — Wake On LAN Cluster

<Callout type="info">
Matter Cluster <code>1283</code>, also written as <code>0x0503</code>, is the <strong>Wake On LAN Cluster</strong>.
This cluster provides an interface for managing low power mode on a device that supports the Wake On LAN or Wake On Wireless LAN (WLAN) protocol. This cluster would be supported on IP devices that have a low power mode AND support the ability to be woken up using the Wake on LAN or Wake on WLAN protocol. This cluster provides the device MAC address which is a required input to the Wake on LAN protocol.
</Callout>

## Attribute `1` / `0x0001` — `LinkLocalAddress`

Path example:

```text
1/1283/1
```

Indicates the current link-local address of the device. Only 128-bit IPv6 link-local addresses is used for this attribute. Some companies may consider MAC Address to be protected data subject to PII handling considerations and will therefore choose not to include it or read it. The MAC Address can often be determined using ARP in IPv4 or NDP in IPv6.

| Property | Value |
|---|---|
| Type | ipv6adr |
| Conformance | `O` |
| Access | R (read: view) |
| Constraint | desc; allowed: 16 |

Example:

```json
{
  "1/1283/1": 1
}
```
