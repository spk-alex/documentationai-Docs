# Matter Cluster 1289 — Keypad Input Cluster

<Callout type="info">
Matter Cluster <code>1289</code>, also written as <code>0x0509</code>, is the <strong>Keypad Input Cluster</strong>.
This cluster provides an interface for key code based input and control on a device like a Video Player or an endpoint like a Content App. This may include text or action commands such as UP, DOWN, and SELECT. This cluster would be supported on Video Player devices as well as devices that support remote control input from a keypad or remote.
</Callout>

## Cluster 1289 Features

The `FeatureMap` attribute (`1/1289/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `NV` | NavigationKeyCodes | `O` | Supports UP, DOWN, LEFT, RIGHT, SELECT, BACK, EXIT, MENU |
| 1 | `LK` | LocationKeys | `O` | Supports CEC keys 0x0A (Settings) and 0x09 (Home) |
| 2 | `NK` | NumberKeys | `O` | Supports numeric input 0..9 |

Example: `FeatureMap` = `0` means no optional feature is enabled; `7` means every feature listed above is enabled.

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1289,
    "command_name": "SendKey",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1289, always use `"cluster_id": 1289`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `SendKey`

## Purpose

On receipt, this must process a keycode as input to the media endpoint. If a device has multiple media endpoints implementing this cluster, such as a casting video player endpoint with one or more content app endpoints, then only the endpoint receiving the command must process the keycode as input. In other words, a specific content app endpoint must NOT process a keycode received by a different content app endpoint. If a second SendKey request with the same KeyCode value is received within 200 ms, then the endpoint will consider the first key press to be a press and hold.

# SmartphoneKey Notes

- Cluster 1289 is **not currently exposed by SmartphoneKey devices**. This page documents the Matter 1.6.1 specification so that future devices can be interpreted without changes to the backend.
- Shadow paths follow `endpoint/1289/attribute`; attribute values that the device reports as unreadable are written as `n/a`.
- Attribute IDs, command IDs and enum values on this page come from the CSA Matter 1.6.1 data model; descriptions are condensed from the specification text.
