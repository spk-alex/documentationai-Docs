# Matter Cluster 1362 — Camera AV Settings User Level Management Cluster

<Callout type="info">
Matter Cluster <code>1362</code>, also written as <code>0x0552</code>, is the <strong>Camera AV Settings User Level Management Cluster</strong>.
This cluster provides an interface into controls associated with the operation of a camera that provides pan, tilt, and zoom functions, either mechanically, or against a digital image.
</Callout>

The `FeatureMap` attribute (`1/1362/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

## Data Types

### `PhysicalMovementEnum`

The PhysicalMovementEnum provides an enumeration of the possible physical movement states in which the camera could be.

| Value | Name | Conformance | Meaning |
|---:|---|---|---|
| 0 | `Idle` | `M` | The camera is idle. |
| 1 | `Moving` | `M` | The camera is moving to a new value of Pan, Tilt, and/or Zoom. |

### `DPTZStruct` (struct)

This type is used to indicate support for the per stream digital pan, tilt, and zoom values.

| Field | Name | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|
| 0 | `VideoStreamID` | VideoStreamID | `M` | — | — |
| 1 | `Viewport` | ViewportStruct | `M` | — | Indicates the per stream viewport applied to this video stream. |

### `MPTZPresetStruct` (struct)

This type is used to save a preset location for mechanical pan, tilt and zoom.

| Field | Name | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|
| 0 | `PresetID` | uint8 | `M` | 1 to MaxPresets | — |
| 1 | `Name` | string | `M` | max length 32 | The is a string representing the name of the Preset. |
| 2 | `Settings` | MPTZStruct | `M` | — | This holds the mechanical pan, tilt and zoom values. |

### `MPTZStruct` (struct)

This type is used to indicate the mechanical pan, tilt, and zoom values.

| Field | Name | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|
| 0 | `Pan` | int16 | `MPAN` | PanMin to PanMax | Indicates the mechanical pan value in angular degrees of angle. |
| 1 | `Tilt` | int16 | `MTILT` | TiltMin to TiltMax | Indicates the mechanical tilt value in angular degrees of angle. |
| 2 | `Zoom` | uint8 | `MZOOM` | 1 to ZoomMax | Indicates the zoom value to use. |

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1362,
    "command_name": "MPTZSetPosition",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1362, always use `"cluster_id": 1362`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
