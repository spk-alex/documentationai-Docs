# Matter Cluster 513 — Thermostat Cluster

<Callout type="info">
Matter Cluster <code>513</code>, also written as <code>0x0201</code>, is the <strong>Thermostat Cluster</strong>.
This cluster provides an interface to the functionality of a thermostat.
</Callout>

## Cluster Identity

| Field | Value |
|---|---|
| Cluster ID decimal | `513` |
| Cluster ID hex | `0x0201` |
| Cluster name | `Thermostat` |
| Cluster revision (Matter 1.6.1) | `11` |
| Role | application |
| Scope | Endpoint |
| PICS code | `TSTAT` |

}

## Cluster 513 Features

The `FeatureMap` attribute (`1/513/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `HEAT` | Heating | `AUTO, O` | Thermostat is capable of managing a heating device |
| 1 | `COOL` | Cooling | `AUTO, O` | Thermostat is capable of managing a cooling device |
| 2 | `OCC` | Occupancy | `O` | Supports Occupied and Unoccupied setpoints |
| 4 | `SB` | Setback | `D` |  |
| 5 | `AUTO` | AutoMode | `O` | Supports a System Mode of Auto |
| 6 | `LTNE` | LocalTemperatureNotExposed | `O` | Thermostat does not expose the LocalTemperature Value in the LocalTemperature attribute |
| 7 | `MSCH` | MatterScheduleConfiguration | `O` | Supports enhanced schedules |
| 8 | `PRES` | Presets | `O` | Thermostat supports setpoint presets |
| 9 | `TEVT` | Events | `P, O` | Thermostat supports events |
| 10 | `TSUGGEST` | ThermostatSuggestions | `[PRES]` | Thermostat supports suggestions |

Example: `FeatureMap` = `0` means no optional feature is enabled; `2039` means every feature listed above is enabled.

# SmartphoneKey Notes

- Cluster 513 is **not currently exposed by SmartphoneKey devices**. This page documents the Matter 1.6.1 specification so that future devices can be interpreted without changes to the backend.
- Shadow paths follow `endpoint/513/attribute`; attribute values that the device reports as unreadable are written as `n/a`.
- Attribute IDs, command IDs and enum values on this page come from the CSA Matter 1.6.1 data model; descriptions are condensed from the specification text.
