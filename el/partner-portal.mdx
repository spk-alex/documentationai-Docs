Το Partner Portal είναι μια σελίδα στο SmartphoneKey Admin Panel (Odoo), όπου ένας εταίρος ενσωμάτωσης λαμβάνει το API key του, συνδέει ένα webhook και παρακολουθεί τις παραδόσεις.

## Απόκτηση πρόσβασης

**Δεν υπάρχει αυτοεγγραφή.** Την πρόσβαση τη ρυθμίζει η SmartphoneKey:

1. Επικοινωνήστε με τον **Vitalii** στη SmartphoneKey (`vitalii@smartphonekey.com`) και ζητήστε πρόσβαση εταίρου.
2. Ο Vitalii δημιουργεί τον οργανισμό σας και έναν λογαριασμό χρήστη με τον ρόλο **Partner**, και σας στέλνει τα στοιχεία σύνδεσης.
3. Συνδεθείτε στο Admin Panel. Η αρχική σελίδα του portal σας εμφανίζει μια κάρτα **Partner Portal** — ανοίξτε την.

Κάθε λογαριασμός του οργανισμού σας που έχει τον ρόλο Partner εργάζεται στην ίδια καταχώρηση, στο ίδιο key και στο ίδιο webhook. Για να προσθέσετε έναν συνάδελφο, ζητήστε από τον Vitalii έναν ακόμη λογαριασμό.

## Ρύθμιση της ενσωμάτωσης

Η σελίδα σας καθοδηγεί σε τρία βήματα, που εμφανίζονται ως γραμμή προόδου στο επάνω μέρος:

1. **Register organization.** Επιβεβαιώστε το **Organization name** και επιλέξτε το **Organization ID** (`orgId`) — 3 έως 64 πεζά γράμματα, ψηφία και παύλες. Το portal προτείνει ένα και ελέγχει ότι είναι διαθέσιμο. Το ID ταυτοποιεί την πλατφόρμα σας σε κάθε κλήση API και webhook (`detail.partnerId`) και **δεν μπορεί να αλλάξει αργότερα**.
2. **Create API key.** Το key που στέλνει η πλατφόρμα σας στο header `X-API-Key` κάθε αιτήματος. Εμφανίζεται **μία φορά**, σε έναν διάλογο που κλείνει μόνο αφού επιβεβαιώσετε ότι το αποθηκεύσατε — φυλάξτε το στον secret manager σας. Στη συνέχεια η σελίδα δείχνει μόνο την αρχή και το τέλος του.
3. **Register webhook.** Η διεύθυνση HTTPS της πλατφόρμας σας όπου η SmartphoneKey παραδίδει events, και τα events που θέλετε: **All events** ή μια λίστα τύπων events (PascalCase, π.χ. `LockCreated`). Το **secret** του webhook εμφανίζεται επίσης μία φορά· κάθε παράδοση το φέρει στο header `X-Webhook-Secret`, ώστε ο server σας να απορρίπτει κλήσεις χωρίς αυτό.

Αν ένα βήμα δεν επιβεβαιωθεί από το API της SmartphoneKey, η σελίδα το κρατά ως μη επιβεβαιωμένο και προσφέρει **Finish**, **Check** ή **Discard** αντί να το επαναλάβει.

## Διαχείριση της ενσωμάτωσης

Μετά τη ρύθμιση, η σελίδα εμφανίζει τις εξής κάρτες:

- **Organization** — το `orgId` σας, και ποιος το καταχώρησε και πότε.
- **API key** — το μασκαρισμένο key. Το **Rotate API key** εκδίδει ένα νέο key, που εμφανίζεται μία φορά. Όσο το τρέχον key είναι ακόμη ενεργό, η περιστροφή απορρίπτεται: ζητήστε πρώτα από τη SmartphoneKey να ανακαλέσει το τρέχον key, μετά κάντε rotate και ενημερώστε αμέσως την πλατφόρμα σας.
- **Webhook** — το URL, τα events και η κατάσταση. Το **Update webhook URL** μεταφέρει τις παραδόσεις σε νέα διεύθυνση HTTPS (επαληθεύεται ξανά εκεί). Το **Replace webhook** δημιουργεί μια νέα συνδρομή με νέο secret και μετά αφαιρεί την παλιά — χρησιμοποιήστε το για χαμένο secret ή για διαφορετικό σύνολο events.
- **Webhook health** — αποτυχημένες παραδόσεις των τελευταίων 15 λεπτών και 24 ωρών, το τελευταίο σφάλμα παράδοσης και τα πρόσφατα σφάλματα.
- **Delivery stats** — σύνολα (παραδοθέντα, αποτυχημένα, επαναλήψεις) και ημερήσιο γράφημα, με **Reset stats** για νέα αφετηρία σε έναν γύρο δοκιμών.
- **Activity** — ποιος καταχώρησε, δημιούργησε, περιέστρεψε ή άλλαξε τι, και πότε.

## Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Πιθανή αιτία | Λύση |
|---------|--------------|-----|
| Δεν υπάρχει κάρτα **Partner Portal** μετά τη σύνδεση | Ο λογαριασμός σας δεν έχει τον ρόλο Partner | Επικοινωνήστε με τον Vitalii |
| "This organization ID is already registered…" | Το ID υπάρχει ήδη στην πλευρά της SmartphoneKey | Επιλέξτε άλλο ID, ή επικοινωνήστε με τη SmartphoneKey για να συνδέσει το υπάρχον με τον λογαριασμό σας |
| Το **Rotate API key** απορρίπτεται | Το τρέχον key είναι ακόμη ενεργό | Ζητήστε από τη SmartphoneKey να το ανακαλέσει και κάντε ξανά rotate |
| Η σελίδα λέει ότι δεν είναι συνδεδεμένη και οι ενέργειες είναι απενεργοποιημένες | Η SmartphoneKey δεν έχει ολοκληρώσει τη ρύθμιση του portal για αυτό το περιβάλλον | Επικοινωνήστε με τη SmartphoneKey |
| Το webhook παραμένει σε `pending` | Το endpoint σας δεν απάντησε στο αίτημα επαλήθευσης με `2xx` | Ελέγξτε τα logs του endpoint σας και βεβαιωθείτε ότι επιστρέφει `2xx` |
