# Matter Cluster 113 — HEPA Filter Monitoring Cluster

<Callout type="info">
Matter Cluster <code>113</code>, also written as <code>0x0071</code>, is the <strong>HEPA Filter Monitoring Cluster</strong>.
</Callout>

<Callout type="info">
This cluster is one of several <strong>alias clusters</strong> that share the same definition (Resource Monitoring Clusters): Activated Carbon Filter Monitoring (&lt;code&gt;114&lt;/code&gt;), Water Tank Level Monitoring (&lt;code&gt;121&lt;/code&gt;). Only the cluster ID and the measured quantity differ.
</Callout>

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 113,
    "command_name": "ResetCondition",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 113, always use `"cluster_id": 113`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
