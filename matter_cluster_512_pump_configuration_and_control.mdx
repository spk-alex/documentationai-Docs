# Matter Cluster 512 — Pump Configuration and Control Cluster

<Callout type="info">
Matter Cluster <code>512</code>, also written as <code>0x0200</code>, is the <strong>Pump Configuration and Control Cluster</strong>.
The Pump Configuration and Control cluster provides an interface for the setup and control of pump devices, and the automatic reporting of pump status information. Note that control of pump speed is not included – speed is controlled by the On/Off and Level Control clusters.
</Callout>

## Cluster 512 Features

The `FeatureMap` attribute (`1/512/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|

| 1 | `PRSCOMP` | CompensatedPressure | `O` | Supports operating in compensated pressure mode |
| 2 | `FLW` | ConstantFlow | `O` | Supports operating in constant flow mode |
| 3 | `SPD` | ConstantSpeed | `O` | Supports operating in constant speed mode |
| 4 | `TEMP` | ConstantTemperature | `O` | Supports operating in constant temperature mode |
| 5 | `AUTO` | Automatic | `O` | Supports operating in automatic mode |
| 6 | `LOCAL` | LocalOperation | `O` | Supports operating using local settings |

Example: `FeatureMap` = `0` means no optional feature is enabled; `127` means every feature listed above is enabled.
