# Matter Cluster 2822 — Meter Identification Cluster

<Callout type="info">
Matter Cluster <code>2822</code>, also written as <code>0x0B06</code>, is the <strong>Meter Identification Cluster</strong>.
This Meter Identification Cluster provides attributes for determining advanced information about utility metering device.
</Callout>

## Cluster 2822 Features

The `FeatureMap` attribute (`1/2822/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `PWRTHLD` | PowerThreshold | `O` | Supports information about power threshold |

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

# Cluster 2822 Commands

Cluster 2822 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 2822 Events

Cluster 2822 defines **no events**.
