# Matter Cluster 98 — Scenes Management Cluster

<Callout type="info">
Matter Cluster <code>98</code>, also written as <code>0x0062</code>, is the <strong>Scenes Management Cluster</strong>.
The Scenes Management cluster provides attributes and commands for setting up and recalling scenes. Each scene corresponds to a set of stored values of specified attributes for one or more clusters on the same end point as the Scenes Management cluster. In most cases scenes are associated with a particular group identifier.
</Callout>

## Attribute `1` / `0x0001` — `SceneTableSize`

Path example:

```text

```

Indicates the number of entries in the Scene Table on this endpoint. This is the total across all fabrics; note that a single fabric cannot use all those entries. ## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 98,
    "command_name": "AddScene",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 98, always use `"cluster_id": 98`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
