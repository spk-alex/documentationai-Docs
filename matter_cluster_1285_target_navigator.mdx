# Matter Cluster 1285 — Target Navigator Cluster

<Callout type="info">
Matter Cluster <code>1285</code>, also written as <code>0x0505</code>, is the <strong>Target Navigator Cluster</strong>.
This cluster provides an interface for UX navigation within a set of targets on a device or endpoint. This cluster would be supported on Video Player devices or devices with navigable user interfaces. This cluster would also be supported on endpoints with navigable user interfaces such as a Content App.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `TargetList`

Path example:

```text
1/1285/0
```

Indicates a list of targets that can be navigated to within the experience presented to the user by the Endpoint (Video Player or Content App). The list must NOT contain any entries with the same Identifier in the TargetInfoStruct object.

| Property | Value |
|---|---|
| Type | list of TargetInfoStruct |
| Conformance | `M` |
| Access | R (read: view) |

Each entry is a `TargetInfoStruct` (see Data Types).

Example:

```json
{
  "1/1285/0": []
}
```

---

## Attribute `1` / `0x0001` — `CurrentTarget`

Path example:

```text
1/1285/1
```

Indicates the Identifier for the target which is currently in foreground on the corresponding Endpoint (Video Player or Content App), or 0xFF to indicate that no target is in the foreground. When not 0xFF, the CurrentTarget is an Identifier value contained within one of the TargetInfoStruct objects in the TargetList attribute.

| Property | Value |
|---|---|
| Type | uint8 |
| Conformance | `O` |
| Access | R (read: view) |
| Constraint | desc |
| Default | `0xFF` |

Example:

```json
{
  "1/1285/1": 1
}
```

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1285,
    "command_name": "NavigateTarget",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1285, always use `"cluster_id": 1285`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
