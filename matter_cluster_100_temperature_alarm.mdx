# Matter Cluster 100 — Temperature Alarm Cluster

<Callout type="info">
Matter Cluster <code>100</code>, also written as <code>0x0064</code>, is the <strong>Temperature Alarm Cluster</strong>.
This cluster is a derived cluster of Alarm Base cluster and provides the alarm definition related to temperature measurements. Support for this cluster is provisional.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Alarm Base cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

For Cluster 100, always use `"cluster_id": 100`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
