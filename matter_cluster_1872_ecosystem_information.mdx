# Matter Cluster 1872 — Ecosystem Information Cluster

<Callout type="info">
Matter Cluster <code>1872</code>, also written as <code>0x0750</code>, is the <strong>Ecosystem Information Cluster</strong>.
The Ecosystem Information Cluster provides extended device information for all the logical devices represented by a Bridged Node. The Ecosystem Information Cluster presents the view of device name and location metadata for presentation by a client of the cluster to a user. This cluster is intended to support Fabric Synchronization and be present on an endpoint with the BridgedNode device type listed in the DeviceTypeList of the endpoint's Descriptor cluster.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `DeviceDirectory`

Path example:

```text
0/1872/0
```

This attribute contains the list of logical devices represented by a Bridged Node. Most of the time this will contain a single entry, but may grow with more complex device compositions (e.g. another bridge.) An empty list indicates that the information is not available.

| Property | Value |
|---|---|
| Type | list of EcosystemDeviceStruct |
| Conformance | `M` |
| Access | R (read: manage, fabric-scoped) |
| Qualities | persisted |

Each entry is a `EcosystemDeviceStruct` (see Data Types).

Example:

```json
{
  "0/1872/0": []
}
```

---

## Attribute `1` / `0x0001` — `LocationDirectory`

Path example:

```text
0/1872/1
```

This attribute contains the list of rooms, areas and groups associated with the DeviceDirectory entries, and must NOT contain locations which are dynamically generated and removed by an ecosystem. (E.g. a location that is generated and removed based on the user being home is not permitted. However, an initially generated location name that does not quickly change is acceptable.) An empty list indicates that the information is not available. LocationDirectory entries is removed if there is no DeviceDirectory that references it.

| Property | Value |
|---|---|
| Type | list of EcosystemLocationStruct |
| Conformance | `M` |
| Access | R (read: manage, fabric-scoped) |
| Qualities | persisted |

Each entry is a `EcosystemLocationStruct` (see Data Types).

Example:

```json
{
  "0/1872/1": []
}
```

# Cluster 1872 Commands

Cluster 1872 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 1872 Events

Cluster 1872 defines **no events**.
