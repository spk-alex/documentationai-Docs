# Matter Cluster 1028 — Flow Measurement Cluster

<Callout type="info">
Matter Cluster <code>1028</code>, also written as <code>0x0404</code>, is the <strong>Flow Measurement Cluster</strong>.
This cluster provides an interface to flow measurement functionality, including configuration and provision of notifications of flow measurements.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `MeasuredValue`

Path example:

```text
1/1028/0
```

Indicates the flow in m^3/h as follows: MeasuredValue = 10 x Flow The null value indicates that the flow measurement is unknown, otherwise the range is as described in Measured Value.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | nullable |
| Constraint | MinMeasuredValue to MaxMeasuredValue |

Example:

```json
{
  "1/1028/0": 1
}
```

# Cluster 1028 Commands

Cluster 1028 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 1028 Events

Cluster 1028 defines **no events**.
