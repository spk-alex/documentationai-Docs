# Matter Cluster 1291 — Audio Output Cluster

<Callout type="info">
Matter Cluster <code>1291</code>, also written as <code>0x050B</code>, is the <strong>Audio Output Cluster</strong>.
This cluster provides an interface for controlling the Output on a Video Player device such as a TV. This cluster would be supported on a device with audio outputs like a Video Player device (Smart TV, TV Setup Top Box, Smart Speaker, etc). This cluster provides the list of available outputs and provides commands for selecting and renaming them.
</Callout>

## Cluster 1291 Features

The `FeatureMap` attribute (`1/1291/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1291,
    "command_name": "SelectOutput",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1291, always use `"cluster_id": 1291`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `SelectOutput`

## Purpose

On receipt, this must change the output on the device to the output at a specific index in the Output List. Note that when the current output is set to an output of type HDMI, adjustments to volume via a Speaker endpoint on the same node may cause HDMI volume up/down commands to be sent to the given HDMI output.

## Command Identity

| Field | Value |
|---|---|

| Direction | client → server |
| Conformance | `M` |

# Command: `RenameOutput`

## Purpose

On receipt, this must rename the output at a specific index in the Output List. Updates to the output name must appear in the device's settings menus. Name updates may automatically be sent to the actual device to which the output connects.
