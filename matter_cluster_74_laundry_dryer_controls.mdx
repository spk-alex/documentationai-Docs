# Matter Cluster 74 — Laundry Dryer Controls Cluster

<Callout type="info">
Matter Cluster <code>74</code>, also written as <code>0x004A</code>, is the <strong>Laundry Dryer Controls Cluster</strong>.
This cluster provides a way to access options associated with the operation of a laundry dryer device type.
</Callout>

## Data Types

### `DrynessLevelEnum`

This enum provides a representation of the level of dryness that will be used while drying in a selected mode. It is up to the device manufacturer to determine the mapping between the enum values and the corresponding temperature level.

| Value | Name | Conformance | Meaning |
|---:|---|---|---|
| 0 | `Low` | `M` | Provides a low dryness level for the selected mode |
| 1 | `Normal` | `M` | Provides the normal level of dryness for the selected mode |
| 2 | `Extra` | `M` | Provides an extra dryness level for the selected mode |
| 3 | `Max` | `M` | Provides the max dryness level for the selected mode |

# Attribute Details

## Attribute `0` / `0x0000` — `SupportedDrynessLevels`

Path example:

```text
1/74/0
```

Indicates the list of supported dryness levels available to the appliance in the currently selected mode. The dryness level values are determined by the manufacturer. At least one dryness level value is provided in the SupportedDrynessLevels list. The list of dryness levels may change depending on the currently-selected Laundry Dryer mode.

| Property | Value |
|---|---|
| Type | list of DrynessLevelEnum |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | 1 to 4 entries |

Example:

```json
{
  "1/74/0": []
}
```

---

## Attribute `1` / `0x0001` — `SelectedDrynessLevel`

Path example:

```text
1/74/1
```

Indicates the currently-selected dryness level and it is the index into the SupportedDrynessLevels list of the selected dryness level. If an attempt is made to write this attribute with a value other than null or a value contained in SupportedDrynessLevels, a CONSTRAINT_ERROR response is sent as the response. If an attempt is made to write this attribute while the device is not in a state that supports modifying the dryness level, an INVALID_IN_STATE error is sent as the response. A value of null indicates that there will be no dryness level setting for the current mode.

| Property | Value |
|---|---|
| Type | DrynessLevelEnum |
| Conformance | `M` |
| Access | R/W (read: view, write: operate) |
| Qualities | nullable |
| Constraint | desc |

Values (`DrynessLevelEnum`):

| Value | Name | Meaning |
|---:|---|---|
| 0 | `Low` | Provides a low dryness level for the selected mode |
| 1 | `Normal` | Provides the normal level of dryness for the selected mode |
| 2 | `Extra` | Provides an extra dryness level for the selected mode |
| 3 | `Max` | Provides the max dryness level for the selected mode |

Example:

```json
{
  "1/74/1": 0
}
```
