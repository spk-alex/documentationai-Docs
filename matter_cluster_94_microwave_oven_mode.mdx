# Matter Cluster 94 — Microwave Oven Mode Cluster

<Callout type="info">
Matter Cluster <code>94</code>, also written as <code>0x005E</code>, is the <strong>Microwave Oven Mode Cluster</strong>.
This cluster is derived from the Mode Base cluster and defines additional mode tags and namespaced enumerated values for microwave oven devices.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Mode Base cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

The `FeatureMap` attribute (`1/94/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.


Exactly one entry in the SupportedModes attribute includes the Normal mode tag in the ModeTags field. The Normal and Defrost mode tags are mutually exclusive and must NOT both be used together in a mode's ModeTags.
