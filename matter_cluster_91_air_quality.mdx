# Matter Cluster 91 — Air Quality Cluster

<Callout type="info">
Matter Cluster <code>91</code>, also written as <code>0x005B</code>, is the <strong>Air Quality Cluster</strong>.
This cluster provides an interface to air quality classification using distinct levels with human-readable labels.
</Callout>

## Cluster 91 Features

The `FeatureMap` attribute (`1/91/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `FAIR` | Fair | `O` | Cluster supports the Fair air quality level |
| 1 | `MOD` | Moderate | `O` | Cluster supports the Moderate air quality level |
| 2 | `VPOOR` | VeryPoor | `O` | Cluster supports the Very poor air quality level |
| 3 | `XPOOR` | ExtremelyPoor | `O` | Cluster supports the Extremely poor air quality level |

Example: `FeatureMap` = `0` means no optional feature is enabled; `15` means every feature listed above is enabled.

## Data Types

### `AirQualityEnum`

The AirQualityEnum provides a representation of the quality of the analyzed air. It is up to the device manufacturer to determine the mapping between the measured values and their corresponding enumeration values.

| Value | Name | Conformance | Meaning |
|---:|---|---|---|
| 0 | `Unknown` | `M` | The air quality is unknown. |
| 1 | `Good` | `M` | The air quality is good. |
| 2 | `Fair` | `FAIR` | The air quality is fair. |
| 3 | `Moderate` | `MOD` | The air quality is moderate. |
| 4 | `Poor` | `M` | The air quality is poor. |
| 5 | `VeryPoor` | `VPOOR` | The air quality is very poor. |
| 6 | `ExtremelyPoor` | `XPOOR` | The air quality is extremely poor. |

# Attribute Details

## Attribute `0` / `0x0000` — `AirQuality`

Path example:

```text
1/91/0
```

Indicates a value from AirQualityEnum that is indicative of the currently measured air quality.

| Property | Value |
|---|---|
| Type | AirQualityEnum |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | desc |

Values (`AirQualityEnum`):

| Value | Name | Meaning |
|---:|---|---|
| 0 | `Unknown` | The air quality is unknown. |
| 1 | `Good` | The air quality is good. |
| 2 | `Fair` | The air quality is fair. |
| 3 | `Moderate` | The air quality is moderate. |
| 4 | `Poor` | The air quality is poor. |
| 5 | `VeryPoor` | The air quality is very poor. |
| 6 | `ExtremelyPoor` | The air quality is extremely poor. |

Example:

```json
{
  "1/91/0": 1
}
```

# Cluster 91 Commands

Cluster 91 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 91 Events

Cluster 91 defines **no events**.
