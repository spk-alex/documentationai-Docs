# Matter Cluster 152 — Device Energy Management Cluster

<Callout type="info">
Matter Cluster <code>152</code>, also written as <code>0x0098</code>, is the <strong>Device Energy Management Cluster</strong>.
This cluster allows a client to manage the power draw of a device. An example of such a client could be an Energy Management System (EMS) which controls an Energy Smart Appliance (ESA). In most deployments the EMS will be the client, and the ESA will host the Device Energy Management Cluster server.
</Callout>

```json
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 152,
    "command_name": "PowerAdjustRequest",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 152, always use `"cluster_id": 152`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

## Payload Fields

| ID | Field | Payload key | Type | Conformance | Constraint | Meaning |

# Cluster 152 Events

| ID | Hex | Event | Priority | Conformance | Description |
|---:|---|---|---|---|---|
| 0 | `0x00` | `PowerAdjustStart` | info | `PA` | This event is generated when the Power Adjustment session is started. |
| 1 | `0x01` | `PowerAdjustEnd` | info | `PA` | This event is generated when the Power Adjustment session ends. |
| 2 | `0x02` | `Paused` | info | `PAU` | This event is generated when the ESA enters the Paused state. |
| 3 | `0x03` | `Resumed` | info | `PAU` | This event is generated when the ESA leaves the Paused state and resumes operation. |

## Event `0` — `PowerAdjustStart`

This event is generated when the Power Adjustment session is started.

This event has no fields.

## Event `1` — `PowerAdjustEnd`

This event is generated when the Power Adjustment session ends.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `Cause` | CauseEnum | `M` | Indicates the reason why the power adjustment session ended. |
| 1 | `Duration` | elapsed-s | `M` | Indicates the number of seconds that the power adjustment session lasted before ending. |
| 2 | `EnergyUse` | energy-mWh | `M` | Indicates the approximate energy used by the ESA during the session. For example, if the ESA was on and was adjusted to be switched off, then this is 0 mWh. |

## Event `2` — `Paused`

This event is generated when the ESA enters the Paused state. There is no data for this event.

This event has no fields.

## Event `3` — `Resumed`

This event is generated when the ESA leaves the Paused state and resumes operation.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `Cause` | CauseEnum | `M` | Indicates the reason why the pause ended. |
