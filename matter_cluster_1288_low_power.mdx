# Matter Cluster 1288 — Low Power Cluster

<Callout type="info">
Matter Cluster <code>1288</code>, also written as <code>0x0508</code>, is the <strong>Low Power Cluster</strong>.
This cluster provides an interface for managing low power mode on a device. This cluster would be supported on an endpoint that represents a physical device with a low power mode. This cluster provides a sleep() command to allow clients to manually put the device into low power mode.
</Callout>

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1288,
    "command_name": "Sleep",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1288, always use `"cluster_id": 1288`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
