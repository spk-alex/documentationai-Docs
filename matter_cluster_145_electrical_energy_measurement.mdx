# Matter Cluster 145 — Electrical Energy Measurement Cluster

<Callout type="info">
Matter Cluster <code>145</code>, also written as <code>0x0091</code>, is the <strong>Electrical Energy Measurement Cluster</strong>.
This cluster provides a mechanism for querying data about the electrical energy imported or provided by the server.
</Callout>

## Cluster 145 Features

The `FeatureMap` attribute (`1/145/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `IMPE` | ImportedEnergy | `O` | Measurement of energy imported by the server |
| 1 | `EXPE` | ExportedEnergy | `O` | Measurement of energy provided by the server |
| 2 | `CUME` | CumulativeEnergy | `O` | Measurements are cumulative |
| 3 | `PERE` | PeriodicEnergy | `O` | Measurements are periodic |
| 4 | `APPE` | ApparentEnergy | `P, O` | Measurements report apparent energy |
| 5 | `REAE` | ReactiveEnergy | `P, O` | Measurements report reactive energy |

Example: `FeatureMap` = `0` means no optional feature is enabled; `63` means every feature listed above is enabled.

## Attribute `1` / `0x0001` — `CumulativeEnergyImported`

Path example:

```text
1/145/1
```

Indicates the most recent measurement of cumulative energy imported by the server over the lifetime of the device, and the timestamp of when the measurement was recorded. The reporting interval of this attribute is manufacturer dependent. The server may choose to omit publication of deltas considered not meaningful. The server must NOT mark this attribute ready for report if the last time this was done was more recently than 1 second ago.

| Property | Value |
|---|---|
| Type | EnergyMeasurementStruct |
| Conformance | `IMPE & CUME` |
| Access | R (read: view) |
| Qualities | nullable, quiet reporting |

Value is a `EnergyMeasurementStruct` struct (see Data Types).

Example:

```json
{
  "1/145/1": {
    "energy": 1,
    "startTimestamp": 0,
    "endTimestamp": 0,
    "startSystime": 0
  }
}
```
