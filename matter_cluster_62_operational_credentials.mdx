# Matter Cluster 62 — Operational Credentials Cluster

<Callout type="info">
Matter Cluster <code>62</code>, also written as <code>0x003E</code>, is the <strong>Operational Credentials Cluster</strong>.
This cluster is used to add or remove Node Operational credentials on a Commissionee or already-configured Node, as well as manage the associated Fabrics.
</Callout>

## Cluster Identity

| Field | Value |
|---|---|
| Cluster ID decimal | `62` |
| Cluster ID hex | `0x003E` |
| Cluster name | `Operational Credentials` |
| Cluster revision (Matter 1.6.1) | `2` |
| Role | utility |
| Scope | Node |
| PICS code | `OPCREDS` |
| Typical endpoint | `0` |

For Cluster 62, always use `"cluster_id": 62`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

## Purpose

This command is used to remove a Fabric from the device. This command is used by Administrators to remove a given Fabric and delete all associated fabric-scoped data. # Command: `AddTrustedRootCertificate`

## Purpose

This command is used to add a trusted root certificate to the device. This command must add a Trusted Root CA Certificate, provided as its Matter Certificate Encoding representation, to the TrustedRootCertificates Attribute list and must ensure the next AddNOC command executed uses the provided certificate as its root of trust. If the certificate from the RootCACertificate field is already installed, based on exact byte-for-byte equality, then this command must succeed with no change to the list. If this command is received without an armed fail-safe context, then this command must fail with a FAILSAFE_REQUIRED status code sent back to the initiator.
