# Matter Cluster 43 — Localization Configuration Cluster

<Callout type="info">
Matter Cluster <code>43</code>, also written as <code>0x002B</code>, is the <strong>Localization Configuration Cluster</strong>.
Nodes should be expected to be deployed to any and all regions of the world. These global regions may have differing common languages, units of measurements, and numerical formatting standards. As such, Nodes that visually or audibly convey information need a mechanism by which they can be configured to use a user’s preferred language, units, etc.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `ActiveLocale`

Path example:

```text
0/43/0
```

The ActiveLocale attribute represents the locale that the Node is currently configured to use when conveying information. The ActiveLocale attribute is a Language Tag as defined by BCP47. The ActiveLocale attribute has a default value assigned by the Vendor and is a value contained within the SupportedLocales attribute. An attempt to write a value to ActiveLocale that is not present in SupportedLocales must result in a CONSTRAINT_ERROR error.

| Property | Value |
|---|---|
| Type | string |
| Conformance | `M` |
| Access | R/W (read: view, write: manage) |
| Qualities | persisted |
| Constraint | max length 35 |
| Default | `MS` |

Example:

```json
{
  "0/43/0": "example"
}
```

---

## Attribute `1` / `0x0001` — `SupportedLocales`

Path example:

```text
0/43/1
```

The SupportedLocales attribute represents a list of locale strings that are valid values for the ActiveLocale attribute. The list must NOT contain any duplicate entries. The ordering of items within the list should NOT express any meaning.

| Property | Value |
|---|---|
| Type | list of string |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | max 32 entries |
| Default | `MS` |

Example:

```json
{
  "0/43/1": []
}
```

# Cluster 43 Commands

Cluster 43 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 43 Events

Cluster 43 defines **no events**.
