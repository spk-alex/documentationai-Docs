# Matter 1.6.1 Clusters — Decimal IDs and Descriptions

This page lists every standard cluster in the **Matter 1.6.1** Application Cluster Specification using the decimal cluster ID format used in SmartphoneKey backend paths and device shadows.

Source: the CSA 1.6.1 data model as published in `project-chip/connectedhomeip` (`data_model/1.6.1/clusters`). Matter 1.6.1 is a maintenance release of 1.6; it adds no new device types.

## Reading a shadow path

For a Matter shadow path like:

```text
1/257/0
```

read it as:

```text
endpoint_id / cluster_id_decimal / attribute_id_decimal
```

So `1/257/0` means **Endpoint 1 / Door Lock cluster (257) / attribute 0 (`LockState`)**.

<Callout type="info">
Cluster IDs below <code>0x8000</code> (decimal 32768) are standard CSA clusters. IDs of the form <code>0xVVVVFCxx</code> (decimal above 4&nbsp;billion, for example <code>308084743</code>) are vendor-specific clusters and are not covered here.
</Callout>

<Callout type="warning">
The previous version of this page (Matter 1.5) contained incorrect decimal IDs for several clusters (energy, media, camera, metering, closure and concentration clusters, among others). All IDs below are taken directly from the specification data model. If you built logic on the old table, re-check the IDs you use.
</Callout>

## How the table is organised

- **Decimal / Hex**: the cluster ID as it appears in shadow paths and as it appears in the specification.
- **Rev**: the cluster revision in Matter 1.6.1 (the value a 1.6.1-compliant device reports in attribute `65533` `ClusterRevision`). Older devices report lower revisions; that is normal.
- **New** marks clusters that did not exist in Matter 1.5.
