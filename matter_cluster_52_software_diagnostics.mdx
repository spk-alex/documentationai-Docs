# Matter Cluster 52 — Software Diagnostics Cluster

<Callout type="info">
Matter Cluster <code>52</code>, also written as <code>0x0034</code>, is the <strong>Software Diagnostics Cluster</strong>.
The Software Diagnostics Cluster provides a means to acquire standardized diagnostics metrics that may be used by a Node to assist a user or Administrator in diagnosing potential problems. The Software Diagnostics Cluster attempts to centralize all metrics that are relevant to the software that may be running on a Node.
</Callout>

## Cluster 52 Features

The `FeatureMap` attribute (`0/52/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `WTRMRK` | Watermarks | `O` | Node makes available the metrics for high watermark related to memory consumption |

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `ThreadMetrics`

Path example:

```text

```

This attribute is a list of ThreadMetricsStruct structs. Each active thread on the Node is represented by a single entry within the ThreadMetrics attribute.

| Property | Value |
|---|---|
| Type | list of ThreadMetricsStruct |
| Conformance | `O` |
| Access | R (read: view) |
| Qualities | change omitted |

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 52,
    "command_name": "ResetWatermarks",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 52, always use `"cluster_id": 52`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

---

# Command: `ResetWatermarks`

## Purpose

This command is used to reset the high watermarks for heap and stack memory. Receipt of this command must reset the following values which track high and lower watermarks: - The StackFreeMinimum field of the ThreadMetrics attribute - The CurrentHeapHighWatermark attribute

## Command Identity

| Field | Value |
|---|---|
| Command ID | `0` |
| Command hex | `0x00` |
| Command name | `ResetWatermarks` |
| Direction | client → server |
| Conformance | `WTRMRK` |
| Response | status |
| Access | (invoke: manage) |

## Payload Fields

This command has no payload fields.
