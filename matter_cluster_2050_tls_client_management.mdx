# Matter Cluster 2050 — TLS Client Management Cluster

<Callout type="info">
Matter Cluster <code>2050</code>, also written as <code>0x0802</code>, is the <strong>TLS Client Management Cluster</strong>.
This Cluster is used to provision TLS Endpoints with enough information to facilitate subsequent connection. Commands in this cluster uniformly use the Large Message qualifier, even when the command doesn't require it, to reduce the testing matrix. This cluster is present on the root node endpoint when required by a device type, may be present on that endpoint otherwise, and must NOT be present on any other Endpoint of any Node.
</Callout>

Path example:

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 2050,
    "command_name": "ProvisionEndpoint",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 2050, always use `"cluster_id": 2050`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
