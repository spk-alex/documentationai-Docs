# Matter Cluster 56 — Time Synchronization Cluster

<Callout type="info">
Matter Cluster <code>56</code>, also written as <code>0x0038</code>, is the <strong>Time Synchronization Cluster</strong>.
Accurate time is required for a number of reasons, including scheduling, display and validating security materials. This section describes a mechanism for Nodes to achieve and maintain time synchronization. The Time Synchronization cluster provides attributes for reading a Node's current time.
</Callout>

For Cluster 56, always use `"cluster_id": 56`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

If the given list is larger than the TimeZoneListMaxSize, the node must respond with RESOURCE_EXHAUSTED and the TimeZone attribute must NOT be updated. If there are no errors in the list, the TimeZone field is copied to the TimeZone attribute.

# Cluster 56 Events

| ID | Hex | Event | Priority | Conformance | Description |
|---:|---|---|---|---|---|
| 0 | `0x00` | `DSTTableEmpty` | info | `TZ` | — |
| 1 | `0x01` | `DSTStatus` | info | `TZ` | — |
| 2 | `0x02` | `TimeZoneStatus` | info | `TZ` | This event is generated when the node changes its time zone offset or name. |
| 3 | `0x03` | `TimeFailure` | info | `M` | This event is generated if the node has not generated a TimeFailure event in the last hour, and the node is unable to get a time from any source. |
| 4 | `0x04` | `MissingTrustedTimeSource` | info | `TSC` | This event is generated if the TrustedTimeSource is set to null upon fabric removal or by a SetTrustedTimeSource command. |

## Event `0` — `DSTTableEmpty`

This event has no fields.

## Event `1` — `DSTStatus`

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `DSTOffsetActive` | bool | `M` | — |

## Event `2` — `TimeZoneStatus`

This event is generated when the node changes its time zone offset or name. It must NOT be sent for DST changes that are not accompanied by a time zone change.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `Offset` | int32 | `M` | Current time zone offset from UTC in seconds. |
| 1 | `Name` | string | `O` | Current time zone name. This name should use the country/city format specified by the IANA Time Zone Database. |

## Event `3` — `TimeFailure`

This event is generated if the node has not generated a TimeFailure event in the last hour, and the node is unable to get a time from any source. This event should NOT be generated more often than once per hour.

This event has no fields.

## Event `4` — `MissingTrustedTimeSource`

This event is generated if the TrustedTimeSource is set to null upon fabric removal or by a SetTrustedTimeSource command. This event must also be generated if the node has not generated a MissingTrustedTimeSource event in the last hour, and the node fails to update its time from the TrustedTimeSource because the TrustedTimeSource is null or the specified peer cannot be reached. MissingTrustedTimeSource events corresponding to a time update should NOT be generated more often than once per hour.

This event has no fields.
