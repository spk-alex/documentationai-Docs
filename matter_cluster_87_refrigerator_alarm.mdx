# Matter Cluster 87 — Refrigerator Alarm Cluster

<Callout type="info">
Matter Cluster <code>87</code>, also written as <code>0x0057</code>, is the <strong>Refrigerator Alarm Cluster</strong>.
This cluster is a derived cluster of Alarm Base cluster and provides the alarm definition related to refrigerator and temperature controlled cabinet devices.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Alarm Base cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 87,
    "command_name": "Reset",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 87, always use `"cluster_id": 87`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
