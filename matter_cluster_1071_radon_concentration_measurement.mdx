# Matter Cluster 1071 — Radon Concentration Measurement Cluster

<Callout type="info">
Matter Cluster <code>1071</code>, also written as <code>0x042F</code>, is the <strong>Radon Concentration Measurement Cluster</strong>.
</Callout>

<Callout type="info">
This cluster is one of several <strong>alias clusters</strong> that share the same definition (Concentration Measurement Clusters): Carbon Monoxide Concentration Measurement (&lt;code&gt;1036&lt;/code&gt;), Carbon Dioxide Concentration Measurement (&lt;code&gt;1037&lt;/code&gt;), Nitrogen Dioxide Concentration Measurement (&lt;code&gt;1043&lt;/code&gt;), Ozone Concentration Measurement (&lt;code&gt;1045&lt;/code&gt;), PM2.5 Concentration Measurement (&lt;code&gt;1066&lt;/code&gt;), Formaldehyde Concentration Measurement (&lt;code&gt;1067&lt;/code&gt;), PM1 Concentration Measurement (&lt;code&gt;1068&lt;/code&gt;), PM10 Concentration Measurement (&lt;code&gt;1069&lt;/code&gt;), Total Volatile Organic Compounds Concentration Measurement (&lt;code&gt;1070&lt;/code&gt;). Only the cluster ID and the measured quantity differ.
</Callout>

## Cluster 1071 Features

The `FeatureMap` attribute (`1/1071/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `MEA` | NumericMeasurement | `O` | Cluster supports numeric measurement of substance |
| 1 | `LEV` | LevelIndication | `O` | Cluster supports basic level indication for substance using the ConcentrationLevel enum |
| 2 | `MED` | MediumLevel | `[LEV]` | Cluster supports the Medium Concentration Level |
| 3 | `CRI` | CriticalLevel | `[LEV]` | Cluster supports the Critical Concentration Level |
| 4 | `PEA` | PeakMeasurement | `[MEA]` | Cluster supports peak numeric measurement of substance |
| 5 | `AVG` | AverageMeasurement | `[MEA]` | Cluster supports average numeric measurement of substance |

Example: `FeatureMap` = `0` means no optional feature is enabled; `63` means every feature listed above is enabled.
