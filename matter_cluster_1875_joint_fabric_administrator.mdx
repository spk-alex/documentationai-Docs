# Matter Cluster 1875 — Joint Fabric Administrator Cluster

<Callout type="info">
Matter Cluster <code>1875</code>, also written as <code>0x0753</code>, is the <strong>Joint Fabric Administrator Cluster</strong>.
An instance of the Joint Fabric Administrator Cluster only applies to Joint Fabric Administrator nodes fulfilling the role of Anchor CA.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `AdministratorFabricIndex`

Path example:

```text
0/1875/0
```

The AdministratorFabricIndex attribute indicates the FabricIndex from the Endpoint 0's Operational Cluster Fabrics attribute (i.e. the Fabric Table) which is associated with the JointFabric. This field has the value of null if there is no fabric associated with the JointFabric.

| Property | Value |
|---|---|
| Type | fabric-idx |
| Conformance | `M` |
| Access | R (read: admin) |
| Qualities | nullable |
| Constraint | 1 to 254 |

Example:

```json
{
  "0/1875/0": 1
}
```

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 1875,
    "command_name": "ICACCSRRequest",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1875, always use `"cluster_id": 1875`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
