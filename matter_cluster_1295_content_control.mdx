# Matter Cluster 1295 — Content Control Cluster

<Callout type="info">
Matter Cluster <code>1295</code>, also written as <code>0x050F</code>, is the <strong>Content Control Cluster</strong>.
This cluster is used for managing the content control (including "parental control") settings on a media device such as a TV, or Set-top Box. This cluster allows to configure content control settings by clients with the Management privilege. It is responsibility of the end product to enforce appropriate right access (for example, to prevent a child from disabling this feature).
</Callout>

## Cluster 1295 Features

The `FeatureMap` attribute (`1/1295/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `ST` | ScreenTime | `O` | Supports managing screen time limits |
| 1 | `PM` | PINManagement | `O` | Supports managing a PIN code which is used for restricting access to configuration of this feature |
| 2 | `BU` | BlockUnrated | `O` | Supports managing content controls for unrated content |
| 3 | `OCR` | OnDemandContentRating | `O` | Supports managing content controls based upon rating threshold for on demand content |
| 4 | `SCR` | ScheduledContentRating | `O` | Supports managing content controls based upon rating threshold for scheduled content |
| 5 | `BC` | BlockChannels | `O` | Supports managing a set of channels that are prohibited |
| 6 | `BA` | BlockApplications | `O` | Supports managing a set of applications that are prohibited |
| 7 | `BTW` | BlockContentTimeWindow | `O` | Supports managing content controls based upon setting time window in which all contents and applications SHALL be blocked |

Example: `FeatureMap` = `0` means no optional feature is enabled; `255` means every feature listed above is enabled.

## Attribute `1` / `0x0001` — `OnDemandRatings`

Path example:

```text
1/1295/1
```

This attribute provides the collection of ratings that are currently valid for this media device. The items should honor the metadata of the on-demand content (e.g. Movie) rating system for one country or region where the media device has been provisioned. For example, for the MPAA system, RatingName may be one value out of "G", "PG", "PG-13", "R", "NC-17".

## Attribute `2` / `0x0002` — `OnDemandRatingThreshold`

Path example:

```text
1/1295/2
```

Indicates a threshold rating as a content filter which is compared with the rating for on-demand content. For example, if the on-demand content rating is greater than or equal to OnDemandRatingThreshold, for a rating system that is ordered from lower viewer age to higher viewer age, then on-demand content is not appropriate for the User and the Node must prevent the playback of content. This attribute is set to one of the values present in the OnDemandRatings attribute. When this attribute changes, the device should make the user aware of any limits of this feature.

| Property | Value |
|---|---|
| Type | string |
| Conformance | `OCR` |
| Access | R (read: view) |
| Constraint | max length 8 |

Example:

```json
{
  "1/1295/2": "example"
}
```

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1295,
    "command_name": "UpdatePIN",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1295, always use `"cluster_id": 1295`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `AddBonusTime`

## Purpose

The purpose of this command is to add the extra screen time for the user. If a client with Operate privilege invokes this command, the media device must check whether the PINCode passed in the command matches the current PINCode value. If these match, then the RemainingScreenTime attribute is increased by the specified BonusTime value. If the PINs do not match, then a response with InvalidPINCode error status is returned, and no changes is made to RemainingScreenTime.
