このカタログには、パートナーが購読できるすべてのイベントを掲載しています。各イベントについて、ソース、発生するタイミング、ペイロードのフィールドを確認できます。

購読と受信の方法については、[Partner Webhooks](/ja/events-webhooks) をご覧ください。

すべての `spk.api` イベントは同じエンベロープ構造を持ちます。ドメインのペイロードは `detail` オブジェクトに包まれており、`detail` にはプロジェクションのメタデータと、`data` 配下の元のイベントが含まれます。

```json
{
  "source": "spk.api",
  "detail-type": "<EventName>",
  "detail": {
    "partnerId": "<your-orgId>",
    "aggregateType": "<LockAggregate|UserAggregate|HubAggregate|...>",
    "aggregateId": "<aggregate id>",
    "version": 7,
    "timestamp": 1745922600123,
    "data": { /* イベント固有のペイロード — 下記参照 */ }
  }
}
```

`detail.timestamp` はプロジェクション時刻を**エポックミリ秒**（数値）で表したものです。`detail.data.timestamp` 内の ISO-8601 タイムスタンプはドメインイベントの発生時刻です。以下に記載するフィールドは `detail.data`、つまり実際のドメインイベントを説明しています。
