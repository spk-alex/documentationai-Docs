# Matter Cluster 155 — Energy Preference Cluster

<Callout type="info">
Matter Cluster <code>155</code>, also written as <code>0x009B</code>, is the <strong>Energy Preference Cluster</strong>.
This cluster provides an interface to specify preferences for how devices should consume energy.
</Callout>

## Cluster 155 Features

The `FeatureMap` attribute (`1/155/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `BALA` | EnergyBalance | `O` | Device can balance energy consumption vs. another priority |
| 1 | `LPMS` | LowPowerModeSensitivity | `O` | Device can adjust the conditions for entering a low power mode |

Example: `FeatureMap` = `0` means no optional feature is enabled; `3` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `EnergyBalances`

Path example:

```text
1/155/0
```

Indicates a list of BalanceStructs, each representing a step along a linear scale of relative priorities. A Step field with a value of zero indicates that the device should entirely favor the priority specified by the first element in EnergyPriorities; whereas a Step field with a value of 100 indicates that the device should entirely favor the priority specified by the second element in EnergyPriorities. The midpoint value of 50 indicates an even split between the two priorities. This contains at least two BalanceStructs.

| Property | Value |
|---|---|
| Type | list of BalanceStruct |
| Conformance | `BALA` |
| Access | R (read: view) |
| Constraint | 2 to 10 entries |

Each entry is a `BalanceStruct` (see Data Types).

Example:

```json
{
  "1/155/0": []
}
```

---

## Attribute `1` / `0x0001` — `CurrentEnergyBalance`

Path example:

```text
1/155/1
```

Indicates the current preference of the user for balancing different priorities during device use. The value of this attribute is the index, 0-based, into the EnergyBalances attribute for the currently selected balance. If an attempt is made to set this attribute to an index outside the maximum index for EnergyBalances, a response with the status code CONSTRAINT_ERROR is returned. If the value of EnergyBalances changes after an update, the device must migrate the value of the CurrentEnergyBalance attribute to the index which the manufacturer specifies most closely matches the previous value, while preserving extreme preferences as follows: 1.

| Property | Value |
|---|---|
| Type | uint8 |
| Conformance | `BALA` |
| Access | R/W (read: view, write: operate) |
| Qualities | persisted |

Example:

```json

}
```

## Attribute `3` / `0x0003` — `LowPowerModeSensitivities`

Path example:

```text
1/155/3
```

Indicates a list of BalanceStructs, each representing a condition or set of conditions for the device to enter a low power mode. This contains at least two BalanceStructs. Each BalanceStruct has a Step field larger than the Step field on the previous BalanceStruct in the list.

| Property | Value |

| Access | R (read: view) |
| Constraint | 2 to 10 entries |

Each entry is a `BalanceStruct` (see Data Types).

```json
}
```

# Cluster 155 Commands

Cluster 155 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 155 Events

Cluster 155 defines **no events**.
