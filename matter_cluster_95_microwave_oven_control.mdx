# Matter Cluster 95 — Microwave Oven Control Cluster

<Callout type="info">
Matter Cluster <code>95</code>, also written as <code>0x005F</code>, is the <strong>Microwave Oven Control Cluster</strong>.
This cluster defines the requirements for the Microwave Oven Control cluster. This cluster has dependencies with the Operational State and Microwave Oven Mode clusters. The Operational State cluster and the Microwave Oven Mode clusters, or derivatives of those clusters must appear on the same endpoint as this cluster.
</Callout>

## Attribute `2` / `0x0002` — `PowerSetting`

Path example:

```text

```

Indicates the power level associated with the operation of the device. If the MinPower, MaxPower, and PowerStep attributes are not supported: - The minimum value of this attribute is 10, - The maximum value of this attribute is 100, - The value is in even multiples of 10, - The default value is 100. If the MinPower, MaxPower, and PowerStep attributes are supported: - The value of this attribute is between MinPower and MaxPower inclusive. - The value of this attribute is such that (PowerSetting - MinPower) % PowerStep == 0

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 95,
    "command_name": "SetCookingParameters",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 95, always use `"cluster_id": 95`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
