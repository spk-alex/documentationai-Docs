# Matter Cluster 1029 — Relative Humidity Measurement Cluster

<Callout type="info">
Matter Cluster <code>1029</code>, also written as <code>0x0405</code>, is the <strong>Relative Humidity Measurement Cluster</strong>.
This is a base cluster. The server cluster provides an interface to water content measurement functionality. The measurement is reportable and may be configured for reporting.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `MeasuredValue`

Path example:

```text
1/1029/0
```

MeasuredValue represents the water content in % as follows: MeasuredValue = 100 x water content Where 0% &lt; = water content &lt; = 100%, corresponding to a MeasuredValue in the range 0 to 10000. The maximum resolution this format allows is 0.01%. MinMeasuredValue and MaxMeasuredValue define the range of the sensor. The null value indicates that the measurement is unknown, otherwise the range is as described in Measured Value.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | nullable |
| Constraint | MinMeasuredValue to MaxMeasuredValue |

Example:

```json
{
  "1/1029/0": 1
}
```
