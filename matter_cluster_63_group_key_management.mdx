# Matter Cluster 63 — Group Key Management Cluster

<Callout type="info">
Matter Cluster <code>63</code>, also written as <code>0x003F</code>, is the <strong>Group Key Management Cluster</strong>.
The Group Key Management cluster manages shared symmetric keys for the node. The cluster is scoped to the node and is a singleton for the node. This cluster maintains a list of groups supported by the node.
</Callout>

## Cluster 63 Features

The `FeatureMap` attribute (`0/63/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `CS` | CacheAndSync | `P` | The ability to support CacheAndSync security policy and MCSP |
| 1 | `GCAST` | Groupcast | `P, O` | The device supports groups using the Groupcast cluster |

Example: `FeatureMap` = `0` means no optional feature is enabled; `3` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `GroupKeyMap`

Path example:

```text
0/63/0
```

If the GCAST feature bit is set in the FeatureMap attribute, the following rules apply to the accessing Fabric: - When Groupcast is adopted (the GroupcastAdoption entry has GroupcastAdopted set to true): - This attribute is empty. - Any attempt to write to this attribute must fail with an INVALID_IN_STATE status code. - Otherwise (Groupcast is not adopted or the entry is missing): - This attribute contains the Group Key Set mappings derived from the Groupcast cluster's Membership attribute (one mapping per group per fabric). - GroupKeyMapStruct entry updates must cause the associated Groupcast cluster's Membership attribute (by GroupID) to be updated with the provided GroupKeySetID.

| Property | Value |
|---|---|
| Type | list of GroupKeyMapStruct |
| Conformance | `M` |
| Access | R/W (read: view, write: manage, fabric-scoped) |
| Qualities | persisted, change omitted |
| Constraint | desc |
| Default | `empty` |

Each entry is a `GroupKeyMapStruct` (see Data Types).

Example:

```json
{
  "0/63/0": []
}
```

## Attribute `1` / `0x0001` — `GroupTable`

Path example:

```text
0/63/1
```

If the GCAST feature is set in the FeatureMap: - If the GroupcastAdoption attribute has an entry for the accessing Fabric and that entry has the GroupcastAdopted field set to true, then this field is empty. - Else this attribute contains the Group mappings computed in equivalence to the Groupcast cluster's Membership attribute (one mapping per group per fabric). This attribute is a list of GroupInfoMapStruct entries. Each entry provides read-only information about how a given logical Group ID maps to a particular set of endpoints, and a name for the group.

| Property | Value |

| Type | list of GroupInfoMapStruct |
| Conformance | `M` |
| Access | R (read: view, fabric-scoped) |
| Constraint | desc |
| Default | `empty` |

Each entry is a `GroupInfoMapStruct` (see Data Types).

Example:

```json
{
  "0/63/1": []
}
```

## Attribute `2` / `0x0002` — `MaxGroupsPerFabric`

Path example:

```text
0/63/2
```

If the Groupcast support is enabled (GCAST feature is set), this is set to 0 indicating group management is done using the Groupcast cluster and not the legacy Groups cluster. Indicates the maximum number of legacy groups that this node supports per fabric. For legacy usage, the value of this attribute is set to be no less than the required minimum supported groups. The length of the GroupKeyMap and GroupTable list attributes must NOT exceed the value of the MaxGroupsPerFabric attribute multiplied by the number of supported fabrics.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Default | `0` |

Example:

```json
{
  "0/63/2": 1
}
```

## Attribute `4` / `0x0004` — `GroupcastAdoption`

Path example:

```text
0/63/4
```

Indicates whether the accessing fabric claims to have migrated to Groupcast. When a Fabric's entry has the GroupcastAdopted field set to true, the behavior of the GroupKeyMap and GroupTable attributes will change. There must NOT be more than 1 entry per fabric in this attribute. If a Fabric has not yet written an entry for themselves, the server must act as if that Fabric had written an entry with GroupcastAdopted set to false, even if not present in the list.

| Property | Value |
|---|---|
| Type | list of GroupcastAdoptionStruct |
| Conformance | `P, GCAST` |
| Access | R/W (read: admin, write: admin, fabric-scoped) |
| Qualities | persisted |
| Constraint | desc |

Each entry is a `GroupcastAdoptionStruct` (see Data Types).

Example:

```json
{
  "0/63/4": []
}
```

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 63,
    "command_name": "KeySetWrite",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 63, always use `"cluster_id": 63`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
