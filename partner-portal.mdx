The Partner Portal is a page in the SmartphoneKey Admin Panel (Odoo) where an integration partner gets its API key, connects a webhook and watches the deliveries.

## Getting access

**There is no self-registration.** Access is set up by SmartphoneKey:

1. Contact **Vitalii** at SmartphoneKey (`vitalii@smartphonekey.com`) and ask for partner access.
2. Vitalii creates your organization and a user account with the **Partner** role, and sends you the sign-in details.
3. Sign in to the Admin Panel. Your portal home shows a **Partner Portal** card — open it.

Every account of your organization that holds the Partner role works on the same registration, key and webhook. To add a colleague, ask Vitalii for another account.

## Set up the integration

The page walks you through three steps, shown as a progress bar at the top:

1. **Register organization.** Confirm the **Organization name** and choose the **Organization ID** (`orgId`) — 3 to 64 lowercase letters, digits and hyphens. The portal suggests one and checks that it is free. The ID identifies your platform in every API call and webhook (`detail.partnerId`) and **cannot be changed later**.
2. **Create API key.** The key your platform sends in the `X-API-Key` header of every request. It is shown **once**, in a dialog you can close only after confirming you saved it — store it in your secret manager. Afterwards the page shows only its beginning and end.
3. **Register webhook.** The HTTPS address on your platform where SmartphoneKey delivers events, and the events you want: **All events** or a list of event types (PascalCase, e.g. `LockCreated`). The webhook **secret** is also shown once; every delivery carries it in the `X-Webhook-Secret` header, so your server can reject calls without it.

If a step is not confirmed by the SmartphoneKey API, the page keeps it as unconfirmed and offers **Finish**, **Check** or **Discard** instead of repeating it.

## Manage the integration

Once set up, the page shows these cards:

- **Organization** — your `orgId`, and who registered it and when.
- **API key** — the masked key. **Rotate API key** issues a new key, shown once. While the current key is still active the rotation is refused: ask SmartphoneKey to revoke the current key first, then rotate and update your platform right away.
- **Webhook** — the URL, events and status. **Update webhook URL** moves deliveries to a new HTTPS address (it is verified again there). **Replace webhook** creates a new subscription with a new secret and then removes the old one — use it for a lost secret or a different set of events.
- **Webhook health** — failed deliveries over the last 15 minutes and 24 hours, the last delivery error and recent errors.
- **Delivery stats** — totals (delivered, failed, retries) and a daily chart, with **Reset stats** to start a fresh baseline for a test round.
- **Activity** — who registered, created, rotated or changed what, and when.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| No **Partner Portal** card after sign-in | Your account does not hold the Partner role | Contact Vitalii |
| "This organization ID is already registered…" | The ID already exists on the SmartphoneKey side | Choose another ID, or contact SmartphoneKey to connect the existing one to your account |
| **Rotate API key** is refused | The current key is still active | Ask SmartphoneKey to revoke it, then rotate again |
| The page says it is not connected and actions are disabled | SmartphoneKey has not finished configuring the portal for this environment | Contact SmartphoneKey |
| Webhook stays in `pending` | Your endpoint has not answered the verification request with `2xx` | Check your endpoint logs and confirm it returns `2xx` |
