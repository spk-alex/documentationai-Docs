# Matter Cluster 64 — Fixed Label Cluster

<Callout type="info">
Matter Cluster <code>64</code>, also written as <code>0x0040</code>, is the <strong>Fixed Label Cluster</strong>.
This cluster is derived from the Label cluster and provides a feature for the device to tag an endpoint with zero or more read-only labels. Examples: - A bridge can use this to indicate grouping of bridged devices. For example: All bridged devices whose endpoints have an entry in their LabelList "room":"bedroom 2" are in the same (bed)room. - A manufacturer can use this to identify a characteristic of an endpoint.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Label cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

# Cluster 64 Commands

Cluster 64 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 64 Events

Cluster 64 defines **no events**.
