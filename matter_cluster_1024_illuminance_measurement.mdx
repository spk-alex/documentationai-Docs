# Matter Cluster 1024 — Illuminance Measurement Cluster

<Callout type="info">
Matter Cluster <code>1024</code>, also written as <code>0x0400</code>, is the <strong>Illuminance Measurement Cluster</strong>.
The Illuminance Measurement cluster provides an interface to illuminance measurement functionality, including configuration and provision of notifications of illuminance measurements.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `MeasuredValue`

Path example:

```text
1/1024/0
```

Indicates the illuminance in Lux (symbol lx) as follows: - MeasuredValue = 10,000 x log10(illuminance) + 1, where 1 lx $&lt;=$ illuminance $&lt;=$ 3.576 Mlx, corresponding to a MeasuredValue in the range 1 to 0xFFFE. The MeasuredValue attribute can take the following values: - 0 indicates a value of illuminance that is too low to be measured, - MinMeasuredValue $&lt;=$ MeasuredValue $&lt;=$ MaxMeasuredValue under normal circumstances, - null indicates that the illuminance measurement is invalid. The MeasuredValue attribute is updated continuously as new measurements are made.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | nullable |
| Constraint | MinMeasuredValue to MaxMeasuredValue; allowed: 0 |

Example:

```json
{
  "1/1024/0": 1
}
```
