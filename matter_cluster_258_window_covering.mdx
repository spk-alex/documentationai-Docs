# Matter Cluster 258 — Window Covering Cluster

<Callout type="info">
Matter Cluster <code>258</code>, also written as <code>0x0102</code>, is the <strong>Window Covering Cluster</strong>.
The window covering cluster provides an interface for controlling and adjusting automatic window coverings such as drapery motors, automatic shades, curtains and blinds.
</Callout>

# Cluster 258 Commands

Cluster 258 has **5 client-to-server commands** and **0 responses**.

| ID | Hex | Command | Direction | Conformance | Response | Description |
|---:|---|---|---|---|---|---|
| 0 | `0x00` | `UpOrOpen` | client → server | `M` | status | On receipt, the window covering will adjust its position so the physical lift/slide and tilt is at the maximum open/up position. |
| 1 | `0x01` | `DownOrClose` | client → server | `M` | status | On receipt, the window covering will adjust its position so the physical lift/slide and tilt is at the maximum closed/down position. |
| 2 | `0x02` | `StopMotion` | client → server | `M` | status | On receipt, the window covering will stop any adjusting to the physical tilt and lift/slide that is currently occurring. |
| 5 | `0x05` | `GoToLiftPercentage` | client → server | `LF & PA_LF, [LF]` | status | This command is used to set the target lift position of the window covering to the percentage value specified in the command. |
| 8 | `0x08` | `GoToTiltPercentage` | client → server | `TL & PA_TL, [TL]` | status | This command is used to set the target tilt position of the window covering to the percentage value specified in the command. |

For Cluster 258, always use `"cluster_id": 258`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.
