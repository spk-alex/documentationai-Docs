# Matter Cluster 46 — Power Source Configuration Cluster

<Callout type="info">
Matter Cluster <code>46</code>, also written as <code>0x002E</code>, is the <strong>Power Source Configuration Cluster</strong>.
This cluster is used to describe the configuration and capabilities of a Device's power system. It provides an ordering overview as well as linking to the one or more endpoints each supporting a Power Source cluster.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `Sources`

Path example:

```text
0/46/0
```

This list contains the set of all power sources capable of participating in the power system of this Node. Each entry in the list is the endpoint number of an endpoint having a Power Source cluster, which corresponds to a physical power source. The endpoint number is unique within the list. The order of power sources on a Node is defined by the Order attribute of its associated Power Source cluster provided on the endpoint.

| Property | Value |
|---|---|
| Type | list of endpoint-no |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | persisted |
| Constraint | max 6 entries |

Example:

```json
{
  "0/46/0": []
}
```

# Cluster 46 Commands

Cluster 46 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 46 Events

Cluster 46 defines **no events**.
