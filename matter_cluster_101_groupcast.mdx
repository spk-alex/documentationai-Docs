# Matter Cluster 101 — Groupcast Cluster

<Callout type="info">
Matter Cluster <code>101</code>, also written as <code>0x0065</code>, is the <strong>Groupcast Cluster</strong>.
The Groupcast Cluster defines a unified, simpler, and more scalable mechanism for configuring, managing, and using groups in Matter. It is designed to replace the legacy Groups cluster, addressing long-standing limitations that have made group configuration complex and inconsistently supported across devices and ecosystems. The Groupcast Cluster consolidates group-related functionality that was previously distributed across multiple clusters into a single, coherent model for membership, addressing, key management, and ACL permissions.
</Callout>

## Cluster 101 Features

The `FeatureMap` attribute (`0/101/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `LN` | Listener | `O` | Supports joining a multicast group of nodes as a listener |
| 1 | `SD` | Sender | `O` | Supports sending multicast message to a targeted group of nodes |
| 2 | `PGA` | PerGroup | `O` | Supports PerGroup multicast addresses |

Example: `FeatureMap` = `0` means no optional feature is enabled; `7` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `Membership`

Path example:

```text
0/101/0
```

Indicates the list of groups memberships currently active on the node. Each entry specifies the group ID and the list of the endpoints that participate in that group, as well as policy for that group. For any single fabric, the server must limit the total number of GroupIDs used across all entries in the Membership attribute to no more than half (rounded down) of the MaxMembershipCount value. If processing a command would cause this per-fabric limit to be exceeded, then the resource exhaustion behavior of the associated command must apply.

| Property | Value |
|---|---|
| Type | list of MembershipStruct |
| Conformance | `M` |
| Access | R (read: view, fabric-scoped) |
| Qualities | persisted |
| Constraint | desc |

Each entry is a `MembershipStruct` (see Data Types).

Example:

```json
{
  "0/101/0": []
}
```

## Attribute `1` / `0x0001` — `MaxMembershipCount`

Path example:

```text

```

Indicates the maximum number of Groups which can be joined and appear in entries of the Membership attribute. This attribute does not specify the maximum number of list entries in the Membership attribute list, but rather the maximum number of different GroupID values which can appear across all entries of the list.

|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | min 10 |

```json

}
```

## Attribute `2` / `0x0002` — `MaxMcastAddrCount`

Path example:

```text
0/101/2
```

Indicates the maximum number of unique multicast addresses the node can support. The value of this attribute is at least 1, to support the IANA Assigned IPv6 Multicast Address. When the PerGroup feature is supported, this attribute should be equal to MaxMembershipCount. However, the value may be less than MaxMembershipCount.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | min 1 |

Example:

```json
{
  "0/101/2": 1
}
```

---

## Attribute `3` / `0x0003` — `UsedMcastAddrCount`

Path example:

```text
0/101/3
```

Indicates the number of unique multicast addresses currently in use by the Groupcast cluster. This count includes the IANA Assigned IPv6 Multicast Address if at least one group is configured to use the IanaAddr policy. This count includes one unique multicast address for each group configured to use the PerGroup policy. The value of this attribute must NOT exceed MaxMcastAddrCount.

| Property | Value |
|---|---|
| Type | uint16 |
| Conformance | `M` |
| Access | R (read: view) |

Example:

```json
{
  "0/101/3": 1
}
```

---

## Attribute `4` / `0x0004` — `FabricUnderTest`

Path example:

```text
0/101/4
```

Indicates the FabricIndex of the fabric currently testing the Groupcast feature with the GroupcastTesting command. The last accessing fabric to have invoked a successful TestGroupcast command that caused testing mode to be engaged is the value indicated. Otherwise, if Groupcast testing is currently disabled, this attribute has a value of zero, which is the invalid FabricIndex value. This attribute is set to zero when the server initializes.

| Property | Value |
|---|---|
| Type | fabric-idx |
| Conformance | `M` |
| Access | R (read: view) |

Example:

```json
{
  "0/101/4": 1
}
```

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 0,
    "cluster_id": 101,
    "command_name": "JoinGroup",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 101, always use `"cluster_id": 101`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `JoinGroup`

## Purpose

This command is used to instruct the server to join a multicast group. It provides a comprehensive way to add all information required to create a new group in one command. This command is used to create a new GroupID or to add specified endpoints to an existing GroupID. This command may also be used to change the OperationalGroupKey associated with an existing GroupID, but if this is the only operation desired, the UpdateGroupKey command should be used instead.

## Command Identity

| Field | Value |
|---|---|
| Command ID | `0` |
| Command hex | `0x00` |
| Command name | `JoinGroup` |
| Direction | client → server |
| Conformance | `M` |
| Response | status |
| Access | (invoke: manage, fabric-scoped) |

## Payload Fields

| ID | Field | Payload key | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|---|
| 0 | `GroupID` | `groupID` | group-id | `M` | min 1 | — |
| 1 | `Endpoints` | `endpoints` | list of endpoint-no | `M` | desc | Indicates the list of endpoints that must receive this multicast group's messages. When joining a group as a Sender only, this field is empty. |
| 2 | `KeySetID` | `keySetID` | uint16 | `M` | min 1 | — |
| 3 | `Key` | `key` | octstr | `O` | allowed: 16 | Indicates the value used to derive the OperationalGroupKey. This key is new for the group, with a unique KeySetID that does not exist on the node yet. |
