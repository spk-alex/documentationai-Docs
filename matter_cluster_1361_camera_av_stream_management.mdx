# Matter Cluster 1361 — Camera AV Stream Management Cluster

<Callout type="info">
Matter Cluster <code>1361</code>, also written as <code>0x0551</code>, is the <strong>Camera AV Stream Management Cluster</strong>.
This cluster is used to allow clients to manage, control, and configure various audio, video, and snapshot streams on a camera. Broadly, this cluster would be used to: 1. Create and manage all streams on the camera. 2.
</Callout>

## Attribute `4` / `0x0004` — `MinViewportResolution`

Path example:

```text

```

Indicates the minimum resolution (width and height) in pixels that the camera allows for its viewport. The choice of the minimum viewport width and height is, typically, directed towards maintaining the best image quality (reduced distortion) for a given size of the video sensor, for different camera functions, e.g., digital zoom. Furthermore, the minimum viewport size and the video sensor size also dictate the upscaling capabilities and requirements of the image processor.

This command must allocate a video stream on the camera and return an allocated video stream identifier.

## Command Identity

| Field | Value |
|---|---|
| Command ID | `3` |
| Command hex | `0x03` |
| Command name | `VideoStreamAllocate` |
| Direction | client → server |
| Conformance | `VDO` |
| Response | VideoStreamAllocateResponse |
| Access | (invoke: manage) |

## Payload Fields

| ID | Field | Payload key | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|---|
| 0 | `StreamUsage` | `streamUsage` | StreamUsageEnum | `M` | allowed: Recording, Analysis, LiveView | Indicates the usage of the stream (Recording, LiveView, etc) that this allocation is for. |
| 1 | `VideoCodec` | `videoCodec` | VideoCodecEnum | `M` | — | Indicates the type of codec used by the allocated video stream. |
| 2 | `MinFrameRate` | `minFrameRate` | uint16 | `M` | 1 to MaxFrameRate | Indicates the minimum frame rate in frames per second of the allocated video stream. |
| 3 | `MaxFrameRate` | `maxFrameRate` | uint16 | `M` | min 1 | Indicates the maximum frame rate in frames per second of the allocated video stream. |
| 4 | `MinResolution` | `minResolution` | VideoResolutionStruct | `M` | — | Indicates the minimum resolution of the allocated video stream. |
| 5 | `MaxResolution` | `maxResolution` | VideoResolutionStruct | `M` | — | Indicates the maximum resolution of the allocated video stream. |
| 6 | `MinBitRate` | `minBitRate` | uint32 | `M` | 1 to MaxBitRate | Indicates the minimum bitrate in bits per second of the allocated video stream. |
| 7 | `MaxBitRate` | `maxBitRate` | uint32 | `M` | min 1 | Indicates the maximum bitrate in bits per second of the allocated video stream. |
| 8 | `KeyFrameInterval` | `keyFrameInterval` | uint16 | `M` | 0 to 65500 | Indicates the duration in milliseconds before a regular key-frame is generated. See KeyFrameInterval for further details. |
| 9 | `WatermarkEnabled` | `watermarkEnabled` | bool | `WMARK` | — | Indicates whether a watermark can be applied on the video stream. A value of TRUE means that watermarking has been enabled for that stream. |
| 10 | `OSDEnabled` | `osdEnabled` | bool | `OSD` | — | — |

`VideoCodec` values (`VideoCodecEnum`): `0` = H264, `1` = HEVC, `2` = VVC, `3` = AV1

## Bridge Command Example

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1361,
    "command_name": "VideoStreamAllocate",
    "payload": {
      "streamUsage": 0,
      "videoCodec": 0,
      "minFrameRate": 1,
      "maxFrameRate": 1,
      "minResolution": {
        "width": 1,
        "height": 1
      },
      "maxResolution": {
        "width": 1,
        "height": 1
      },
      "minBitRate": 1,
      "maxBitRate": 1,
      "keyFrameInterval": 0
    }
  }
}
```

The device answers with `VideoStreamAllocateResponse` (see below).

# Command: `SetStreamPriorities`

## Purpose

This command must set the relative priorities of the various stream usages on the camera. The camera then bases its allocation of resources for each stream allocation based on the order of these stream priorities. In order to avoid the complexity of dynamically changing the configurations of currently active streams, this command must NOT be invoked when there are allocated streams. If changes are required while streams are allocated, all existing streams would need to be deallocated before invoking this command.

## Command Identity

| Field | Value |
|---|---|
| Command ID | `11` |
| Command hex | `0x0B` |
| Command name | `SetStreamPriorities` |
| Direction | client → server |
| Conformance | `M` |
| Response | status |
| Access | (invoke: admin) |

## Payload Fields

| ID | Field | Payload key | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|---|
| 0 | `StreamPriorities` | `streamPriorities` | list of StreamUsageEnum | `M` | desc | The StreamPriorities field contains a list of stream usages in decreasing order of stream priorities, starting at index 0 of the list, with no duplicate values allowed, and only containing entries found in SupportedStreamUsages. |

## Bridge Command Example

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1361,
    "command_name": "SetStreamPriorities",
    "payload": {
      "streamPriorities": []
    }
  }
}
```

# Command: `CaptureSnapshotResponse`

## Purpose

This command is sent by the device in response to the CaptureSnapshot command, carrying the requested snapshot.

## Command Identity

| Field | Value |
|---|---|
| Command ID | `13` |
| Command hex | `0x0D` |
| Command name | `CaptureSnapshotResponse` |
| Direction | server → client (response) |
| Conformance | `SNP` |

## Response Fields

| ID | Field | Payload key | Type | Conformance | Constraint | Meaning |
|---:|---|---|---|---|---|---|
| 0 | `Data` | `data` | octstr | `M` | — | The Data field is an octet string representing the image data. |
| 1 | `ImageCodec` | `imageCodec` | ImageCodecEnum | `M` | — | The ImageCodec field is an ImageCodecEnum representing the codec used to encode the image. This must match the value found in the corresponding allocated snapshot stream and is provided for convenience. |
| 2 | `Resolution` | `resolution` | VideoResolutionStruct | `M` | — | The Resolution field is a VideoResolutionStruct representing the resolution of the supplied image. |

`ImageCodec` values (`ImageCodecEnum`): `0` = JPEG, `1` = HEIC
