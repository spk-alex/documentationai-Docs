# Matter Cluster 1293 — Application Basic Cluster

<Callout type="info">
Matter Cluster <code>1293</code>, also written as <code>0x050D</code>, is the <strong>Application Basic Cluster</strong>.
This cluster provides information about a Content App running on a Video Player device which is represented as an endpoint. The cluster server for this cluster should be supported on each endpoint that represents a Content App on a Video Player device. This cluster provides identification information about the Content App such as vendor and product.
</Callout>
