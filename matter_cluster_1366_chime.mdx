# Matter Cluster 1366 — Chime Cluster

<Callout type="info">
Matter Cluster <code>1366</code>, also written as <code>0x0556</code>, is the <strong>Chime Cluster</strong>.
This cluster provides facilities to configure and play Chime sounds, such as those used in a doorbell.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `InstalledChimeSounds`

Path example:

```text
1/1366/0
```

This attribute contains all installed chime sounds, represented by a list of Chime Sounds. Each entry in this list has a unique ChimeID value and a unique Name value.

| Property | Value |
|---|---|
| Type | list of ChimeSoundStruct |
| Conformance | `M` |
| Access | R (read: view) |
| Constraint | 1 to 255 entries |

Each entry is a `ChimeSoundStruct` (see Data Types).

Example:

```json
{
  "1/1366/0": []
}
```

---

## Attribute `1` / `0x0001` — `SelectedChime`

Path example:

```text
1/1366/1
```

Indicates the currently selected chime sound that will be played when PlayChimeSound is invoked and is the ChimeID value for the requested Chime Sound within InstalledChimeSounds. This attribute may be written by the client to request a different chime sound. An attempt to write a value that is not contained within InstalledChimeSounds is failed with a NOT_FOUND response. Writes to this attribute while a chime is currently playing must NOT affect the playback in progress and only apply starting at the next PlayChimeSound command invocation.

| Property | Value |
|---|---|
| Type | uint8 |
| Conformance | `M` |
| Access | R/W (read: view, write: operate) |
| Qualities | persisted |

Example:

```json
{
  "1/1366/1": 1
}
```

---

## Attribute `2` / `0x0002` — `Enabled`

Path example:

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 1366,
    "command_name": "PlayChimeSound",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 1366, always use `"cluster_id": 1366`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `PlayChimeSound`

## Purpose

This command will play the currently selected chime or the chime passed in. In either case the server must generate the ChimeStartedPlaying event.
