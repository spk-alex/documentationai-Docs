# Matter Cluster 42 — OTA Software Update Requestor Cluster

<Callout type="info">
Matter Cluster <code>42</code>, also written as <code>0x002A</code>, is the <strong>OTA Software Update Requestor Cluster</strong>.

## Attribute `1` / `0x0001` — `UpdatePossible`

Path example:

```text
0/42/1
```

This field is set to True if the OTA Requestor is currently able to be updated. Otherwise, it is set to False in case of any condition preventing update being possible, such as insufficient capacity of an internal battery. This field is merely informational for diagnostics purposes and must NOT affect the responses provided by an OTA Provider to an OTA Requestor.

# Cluster 42 Events

| ID | Hex | Event | Priority | Conformance | Description |
|---:|---|---|---|---|---|

## Event `0` — `StateTransition`

This event is generated when a change of the UpdateState attribute occurs due to an OTA Requestor moving through the states necessary to query for updates.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `PreviousState` | UpdateStateEnum | `M` | This field is set to the state that preceded the transition causing this event to be generated, if such a state existed. If no previous state exists, the value is Unknown. |
| 1 | `NewState` | UpdateStateEnum | `M` | This field is set to the state now in effect through the transition causing this event to be generated. |
| 2 | `Reason` | ChangeReasonEnum | `M` | This field is set to the reason why this event was generated. |
| 3 | `TargetSoftwareVersion` | uint32 (nullable) | `M` | This field is set to the target SoftwareVersion which is the subject of the operation, whenever the NewState is Downloading, Applying or RollingBack. Otherwise TargetSoftwareVersion is null. |

## Event `1` — `VersionApplied`

This event is generated whenever a new version starts executing after being applied due to a software update. This event should be generated even if a software update was done using means outside of this cluster.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `SoftwareVersion` | uint32 | `M` | This field is set to the same value as the one available in the Software Version attribute of the Basic Information Cluster for the newly executing version. |
| 1 | `ProductID` | uint16 | `M` | — |

## Event `2` — `DownloadError`

This event is generated whenever an error occurs during OTA Requestor download operation.

| ID | Field | Type | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `SoftwareVersion` | uint32 | `M` | This field is set to the value of the SoftwareVersion being downloaded, matching the SoftwareVersion field of the QueryImageResponse that caused the failing download to take place. |
| 1 | `BytesDownloaded` | uint64 | `M` | This field is set to the number of bytes that have been downloaded during the failing transfer that caused this event to be generated. |
| 2 | `ProgressPercent` | uint8 (nullable) | `M` | This field is set to the nearest integer percent value reflecting how far within the transfer the failure occurred during the failing transfer that caused this event to be generated, unless the total length of the transfer is unknown, in which case it is null. |
| 3 | `PlatformCode` | int64 (nullable) | `M` | This field should be set to some internal product-specific error code, closest in temporal/functional proximity to the failure that caused this event to be generated. Otherwise, it is null. |
