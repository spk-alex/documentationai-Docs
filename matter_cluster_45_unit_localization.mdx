# Matter Cluster 45 — Unit Localization Cluster

<Callout type="info">
Matter Cluster <code>45</code>, also written as <code>0x002D</code>, is the <strong>Unit Localization Cluster</strong>.
Nodes should be expected to be deployed to any and all regions of the world. These global regions may have differing preferences for the units in which values are conveyed in communication to a user. As such, Nodes that visually or audibly convey measurable values to the user need a mechanism by which they can be configured to use a user’s preferred unit.
</Callout>

## Cluster 45 Features

The `FeatureMap` attribute (`0/45/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `TEMP` | TemperatureUnit | `O` | The Node can be configured to use different units of temperature when conveying values to a user |

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `TemperatureUnit`

Path example:

```text
0/45/0
```

Indicates the unit for the Node to use only when conveying temperature in communication to the user, for example such as via a user interface on the device. If provided, this value must take priority over any unit implied through the ActiveLocale Attribute. An attempt to write to this attribute with a value not included in the SupportedTemperatureUnits attribute list must result in a CONSTRAINT_ERROR.

| Property | Value |
|---|---|
| Type | TempUnitEnum |
| Conformance | `TEMP` |
| Access | R/W (read: view, write: manage) |
| Qualities | persisted |

Values (`TempUnitEnum`):

| Value | Name | Meaning |
|---:|---|---|
| 0 | `Fahrenheit` | Temperature conveyed in Fahrenheit |
| 1 | `Celsius` | Temperature conveyed in Celsius |
| 2 | `Kelvin` | Temperature conveyed in Kelvin |

Example:

```json
{
  "0/45/0": 0
}
```

---

## Attribute `1` / `0x0001` — `SupportedTemperatureUnits`

Path example:

```text
0/45/1
```

Indicates a list of units supported by the Node to be used when writing the TemperatureUnit attribute of this cluster. Each entry in the list is unique.

| Property | Value |
|---|---|
| Type | list of TempUnitEnum |
| Conformance | `TEMP` |
| Access | R (read: view) |
| Constraint | 2 to 3 entries |

Example:

```json
{
  "0/45/1": []
}
```

# Cluster 45 Commands

Cluster 45 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 45 Events

Cluster 45 defines **no events**.
