# Matter Cluster 1026 — Temperature Measurement Cluster

<Callout type="info">
Matter Cluster <code>1026</code>, also written as <code>0x0402</code>, is the <strong>Temperature Measurement Cluster</strong>.
This cluster provides an interface to temperature measurement functionality, including configuration and provision of notifications of temperature measurements.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `MeasuredValue`

Path example:

```text
1/1026/0
```

Indicates the measured temperature. The null value indicates that the temperature is unknown.

| Property | Value |
|---|---|
| Type | temperature |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | nullable |
| Constraint | MinMeasuredValue to MaxMeasuredValue |

# Cluster 1026 Commands

Cluster 1026 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 1026 Events

Cluster 1026 defines **no events**.

# SmartphoneKey Notes

- Temperature is reported in hundredths of a degree Celsius: `2150` = 21.50 °C.
- Shadow paths follow `endpoint/1026/attribute`; attribute values that the device reports as unreadable are written as `n/a`.
- Attribute IDs, command IDs and enum values on this page come from the CSA Matter 1.6.1 data model; descriptions are condensed from the specification text.
