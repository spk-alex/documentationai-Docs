# Matter Cluster 1072 — Soil Measurement Cluster

<Callout type="info">
Matter Cluster <code>1072</code>, also written as <code>0x0430</code>, is the <strong>Soil Measurement Cluster</strong>.
This cluster provides an interface to soil measurement functionality, including configuration and provision of notifications of soil measurements.
</Callout>

# Attribute Details

## Attribute `0` / `0x0000` — `SoilMoistureMeasurementLimits`

Path example:

```text
1/1072/0
```

Indicates the limits for the SoilMoistureMeasuredValue attribute. Given the measurements are in percentage, the MinMeasuredValue field in the SoilMoistureMeasurementLimits attribute must NOT be less than 0 and must NOT be greater than 99. The MaxMeasuredValue field in the SoilMoistureMeasurementLimits attribute must NOT be less than (SoilMoistureMinMeasurableValue + 1) and must NOT be greater than 100. The MeasurementType field value is set to SoilMoisture.

| Property | Value |
|---|---|
| Type | MeasurementAccuracyStruct |
| Conformance | `M` |
| Access | R (read: view) |

Example:

```json
{
  "1/1072/0": 0
}
```

---

## Attribute `1` / `0x0001` — `SoilMoistureMeasuredValue`

Path example:

```text
1/1072/1
```

Indicates the water content of the soil in percentage. The null value indicates that the measurement is unknown e.g. no measurement has been performed yet.

| Property | Value |
|---|---|
| Type | percent |
| Conformance | `M` |
| Access | R (read: view) |
| Qualities | nullable |
| Constraint | SoilMoistureMeasurementLimits to SoilMoistureMeasurementLimits |

Example:

```json
{
  "1/1072/1": 1
}
```

# Cluster 1072 Commands

Cluster 1072 defines **no commands**. It is read (and, for writable attributes, written) through attribute access only.

# Cluster 1072 Events

Cluster 1072 defines **no events**.
