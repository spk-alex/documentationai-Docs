# Matter Cluster 92 — Smoke CO Alarm Cluster

<Callout type="info">
Matter Cluster <code>92</code>, also written as <code>0x005C</code>, is the <strong>Smoke CO Alarm Cluster</strong>.
This cluster provides an interface for observing and managing the state of smoke and CO alarms.
</Callout>

Indicates whether the power resource fault detection mechanism is currently triggered at the device. # Command: `SelfTestRequest`

## Purpose

This command must initiate a device self-test. The return status indicates whether the test was successfully initiated. Only one SelfTestRequest may be processed at a time. When the value of the ExpressedState attribute is any of SmokeAlarm, COAlarm, Testing, InterconnectSmoke, InterconnectCO, the device must NOT execute the self-test, and returns status code BUSY.

- Shadow paths follow `endpoint/92/attribute`; attribute values that the device reports as unreadable are written as `n/a`.
- Attribute IDs, command IDs and enum values on this page come from the CSA Matter 1.6.1 data model; descriptions are condensed from the specification text.
