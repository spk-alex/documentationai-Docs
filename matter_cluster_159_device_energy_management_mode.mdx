# Matter Cluster 159 — Device Energy Management Mode Cluster

<Callout type="info">
Matter Cluster <code>159</code>, also written as <code>0x009F</code>, is the <strong>Device Energy Management Mode Cluster</strong>.
This cluster is derived from the Mode Base cluster and defines additional mode tags and namespaced enumerated values for Device Energy Management devices.
</Callout>

<Callout type="info">
This cluster is <strong>derived from the Mode Base cluster</strong>: it inherits the base attributes, commands and data types listed below and adds the cluster-specific values. Where the base definition applies, the base text is used.
</Callout>

## Cluster 159 Features

The `FeatureMap` attribute (`1/159/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `DEPONOFF` | OnOff | `X` | Dependency with the OnOff cluster |

Example: `FeatureMap` = `0` means no optional feature is enabled; `1` means every feature listed above is enabled.

# Attribute Details

## Attribute `0` / `0x0000` — `SupportedModes`

Path example:

```text
1/159/0
```

At least one entry in the SupportedModes attribute includes the NoOptimization mode tag in the ModeTags field. At least one entry in the SupportedModes attribute includes the LocalOptimization mode tag in the ModeTags field list. At least one entry in the SupportedModes attribute includes the GridOptimization mode tag in the ModeTags field list. An entry in the SupportedModes attribute that includes one of an DeviceOptimization, LocalOptimization, or GridOptimization tags must NOT also include NoOptimization tag.

## Bridge Command Payload Format

The bridge accepts Matter commands in this structure:

```json
{
  "message_id": "1",
  "command": "device_command",
  "args": {
    "endpoint_id": 1,
    "cluster_id": 159,
    "command_name": "ChangeToMode",
    "payload": {},
    "timed_request_timeout_ms": 1000
  }
}
```

For Cluster 159, always use `"cluster_id": 159`. Payload keys are the command field names in lowerCamelCase. Octet-string fields are base64-encoded. `timed_request_timeout_ms` is required for timed commands and ignored otherwise.

# Command: `ChangeToMode`

## Purpose

This command is used to change device modes. On receipt of this command the device must respond with a ChangeToModeResponse command.
