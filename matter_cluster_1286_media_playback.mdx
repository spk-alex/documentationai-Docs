# Matter Cluster 1286 — Media Playback Cluster

<Callout type="info">
Matter Cluster <code>1286</code>, also written as <code>0x0506</code>, is the <strong>Media Playback Cluster</strong>.
This cluster provides an interface for controlling Media Playback (PLAY, PAUSE, etc) on a media device such as a TV, Set-top Box, or Smart Speaker. This cluster server would be supported on Video Player devices or endpoints that provide media playback, such as a Content App. This cluster provides an interface for controlling Media Playback.
</Callout>

# Command: `Rewind`

## Purpose

This command is used to rewind the media. Upon receipt, this must start playback of the media backward in case the media is currently playing in the forward direction or is not playing. If the playback is already happening in the backwards direction receipt of this command must increase the speed of the media playback backwards. Different "rewind" speeds may be reflected on the media playback device based upon the number of sequential calls to this function and the capability of the device.

## Command Identity

| Field | Value |

# SmartphoneKey Notes

- Cluster 1286 is **not currently exposed by SmartphoneKey devices**. This page documents the Matter 1.6.1 specification so that future devices can be interpreted without changes to the backend.
- Shadow paths follow `endpoint/1286/attribute`; attribute values that the device reports as unreadable are written as `n/a`.
- Attribute IDs, command IDs and enum values on this page come from the CSA Matter 1.6.1 data model; descriptions are condensed from the specification text.
