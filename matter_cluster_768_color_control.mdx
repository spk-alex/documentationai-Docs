# Matter Cluster 768 — Color Control Cluster

<Callout type="info">
Matter Cluster <code>768</code>, also written as <code>0x0300</code>, is the <strong>Color Control Cluster</strong>.
This cluster provides an interface for changing the color of a light. Color is specified according to the CIE 1931 Color space. Color control is carried out in terms of x,y values, as defined by this specification.
</Callout>

## Cluster 768 Features

The `FeatureMap` attribute (`1/768/65532`) is a bitmap. Each bit set means the device implements that feature and the attributes and commands that depend on it.

| Bit | Code | Feature | Conformance | Meaning |
|---:|---|---|---|---|
| 0 | `HS` | HueSaturation | `EHUE, O` | Supports color specification via hue/saturation. |
| 1 | `EHUE` | EnhancedHue | `CL, O` | Enhanced hue is supported. |
| 2 | `CL` | ColorLoop | `O` | Color loop is supported. |
| 3 | `XY` | XY | `O` | Supports color specification via XY. |
| 4 | `CT` | ColorTemperature | `O` | Supports specification of color temperature. |

Example: `FeatureMap` = `0` means no optional feature is enabled; `31` means every feature listed above is enabled.

## Attribute `2` / `0x0002` — `RemainingTime`

Path example:

```text
1/768/2
```

Indicates the time remaining, in 1/10ths of a second, until transitions due to the currently active command will be complete. Changes to this attribute only be marked as reportable in the following cases: - When it changes from 0 to any value higher than 10, or - When it changes, with a delta larger than 10, caused by the invoke of a command, or - When it changes to 0. For commands with a transition time or changes to the transition time less than 1 second, changes to this attribute must NOT be reported. As this attribute is not being reported during a regular countdown, clients should NOT rely on the reporting of this attribute in order to keep track of the remaining duration.

| Type | uint16 |
| Conformance | `O` |
| Access | R (read: view) |
| Qualities | quiet reporting |
| Constraint | max 65534 |
