# Matter Cluster 516 — Thermostat User Interface Configuration Cluster

<Callout type="info">
Matter Cluster <code>516</code>, also written as <code>0x0204</code>, is the <strong>Thermostat User Interface Configuration Cluster</strong>.
This cluster provides an interface to allow configuration of the user interface for a thermostat, or a thermostat controller device, that supports a keypad and LCD screen.
</Callout>

## Attribute `2` / `0x0002` — `ScheduleProgrammingVisibility`

Path example:

```text
1/516/2
```

This attribute is used to hide the weekly schedule programming functionality or menu on a thermostat from a user to prevent local user programming of the weekly schedule. The schedule programming may still be performed via a remote interface, and the thermostat may operate in schedule programming mode. This attribute is designed to prevent local tampering with or disabling of schedules that may have been programmed by users or service providers via a more capable remote interface. The programming schedule must continue to run even though it is not visible to the user locally at the thermostat.

| Property | Value |
|---|---|
| Type | ScheduleProgrammingVisibilityEnum |
| Conformance | `O` |
| Access | R/W (read: view, write: manage) |

Values (`ScheduleProgrammingVisibilityEnum`):

| Value | Name | Meaning |
|---:|---|---|
| 0 | `ScheduleProgrammingPermitted` | Local schedule programming functionality is enabled at the thermostat |
| 1 | `ScheduleProgrammingDenied` | Local schedule programming functionality is disabled at the thermostat |

Example:

```json

  "1/516/2": 0
}
```
